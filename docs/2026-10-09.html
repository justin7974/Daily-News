Synthesis Superintelligence: from Semiconductors to Superconductors — Periodic Labs’ Liam Fedus and Ekin Dogus Cubuk
Periodic Labs 把强化学习的反馈接到真实实验室，试图让模型通过预测、合成与材料表征的循环发现新材料。Liam Fedus 和 Ekin Doğuş Çubuk 强调，实验有测量噪声、设备差异与缺失信息，不能照搬数学和编程中容易判定对错的训练方式。模拟与密度泛函计算帮助筛选方向，但最终仍需高通量物理实验检验，样本效率也受设备吞吐约束。半导体、磁性材料与超导体属于团队讨论的目标，访谈没有证明室温超导等目标已经实现。
🦐点评：团队把固态化学家、硬件工程师和 LLM 专家放进同一实验室，这种组织能力比单个模型更难复制；尽调要追踪每轮实验是否降低下一轮的成本，以及客户是否愿意为可复验的材料结果付钱，才能区分数据壁垒和昂贵研发外包。
www.latent.space
You Need a New CFO
a16z 观察到财务团队开始自己搭建 Agent，CFO 的稀缺能力逐渐转向设计数据、流程与控制系统。作者称 Anthropic 财务团队维护七十多个专用 AI Skills，其中一项可生成九成至九成五完整的月度财务审阅，将数小时工作压至约三十分钟。最精简团队把财务人员占比从传统约 5% 向 2% 的目标调整，文章并未证明这是普遍实现的结果。软件接近正式账簿后，数字溯源、凭证保留和入账审批成为产品核心；案例主要来自作者及其投资组合。
🦐点评：文中最重度的使用者是 Anthropic 税务负责人：最懂业务的人才知道该自动化什么，也会自己做工具；财务 SaaS 的竞争门槛因而上移到跨系统执行与审计责任，只卖报表或提示词模板的产品更容易被客户内部替代。
www.a16z.news
The model that didn't exist, so you made it yourself
Hugging Face 作者用 ML Intern 将 9B 的图像提示词改写器蒸馏为可在 CPU 上运行的 0.8B 模型，项目计算费用约十六美元。作者报告输出格式有效率为 99.7%，这不等同于内容质量或任务准确率；另一个柑橘病害模型在 335 张测试照片上的识别准确率从 14.9% 提升至 52.8%。Agent 负责规划、试跑、训练、评测与发布，启动付费任务前需获得预算。六个项目合计约一百零三美元，仅计 GPU 和 CPU 作业费用，未包括人的时间等完整成本。
🦐点评：作者发现 Huggy LoRA 训练到五百步后会污染无关提示词的画风：训练变便宜之后，垂直模型公司的收费理由更依赖客户专有数据与副作用验收；只展示一个训练成功案例，很难支撑长期溢价。
huggingface.co
Disrupting AI-enabled “false front” operations
OpenAI 称已封禁来自俄罗斯和伊朗的两组隐蔽影响行动，它们借假记者或假智库把地缘政治内容投向真实媒体。伊朗行动使用七个记者身份，俄罗斯行动则似乎让不知情的拉美人员为前台机构工作；AI 既参与内容生成，也被大量用于内部汇报。OpenAI 将两者的传播突破等级分别评为五级和四级，前者是其首次报告的五级案例。该等级反映潜在传播范围，不能当作受众意见已被改变的证明，也并非所有传播内容都由其模型生成。
🦐点评：俄罗斯行动使用 ChatGPT 最多的是向上级写报告，还会夸大自身成效；企业信任产品若只检测文案是否由 AI 生成，会漏掉真实员工与真实媒体形成的背书，更有价值的是验证身份、委托关系和内容来源链。
openai.com
Claude Code v2.1.295
Claude Code v2.1.295 为命令与 HTTP hooks 加入失败时阻断动作的选项，覆盖启动失败、超时和异常退出，安全检查不再只能在成功运行后发挥作用。更新还修复了工具限制未覆盖后注册工具、以及护栏收到被截断输入却未报错等问题。企业网关新增上游首 token 超时控制、模型路由名单和请求编号，使故障切换与审计更可管理。以上是官方版本说明列出的行为变化，不能据此认定所有部署已经启用这些设置。
🦐点评：版本同时修复了远程 MCP 在长时间中断后不恢复连接的问题：企业客户购买的是持续可用、权限可信的执行系统，单独做 MCP 连接或基础护栏的创业公司，会受到宿主持续补齐能力的挤压，必须找到跨宿主的管理价值。
github.com
