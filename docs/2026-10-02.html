SCOOP: Benchmark Backs Early-Stage Startup Tendrils Compute as Chip Momentum Builds
Benchmark 据报道领投 Tendrils Compute，后者已讨论可能超过十亿美元估值的后续融资；两轮均未正式公开，Benchmark 未回应。英国剑桥团队由 Nils Cremer 领导，押注 interaction nets 计算架构，试图减少多核 CPU 的协调成本。其判断是，Agent 连续推理与工具调用可能使 CPU 成为新瓶颈。报道还列出 Etched、Fractile、OLIX 等芯片融资，并提醒开发周期、资本强度和周期性风险；可读正文不含付费市场地图。
🦐点评：Tendrils 把瓶颈指向 CPU，给了芯片投资一个区别于 GPU 替代的新假设。尽调应拿真实 Agent 工作流测端到端收益：如果等待浏览器、网络和工具才占大头，更快 CPU 就难支撑客户迁移。接近十亿美元的融资讨论，已经要求团队在量产前证明这条因果链。
www.newcomer.co
[AINews] Gemini 4 Argon: GDM’s answer to Astra/Fable, with 1M output
Gemini 4 Argon 的便宜来自折扣，未必来自更少的推理消耗。Latent Space 汇总 Artificial Analysis 评测：折扣下每任务约 1.99 美元，Astra 为 3.26 美元；恢复标准价格后 Argon 约为 3.98 美元，且平均输出量更高。Google 宣称它在十九项公布的基准中领先十三项，但当前只向 Fairwind 的政府用户和受信任网络防御者开放。百万 token 输出通过实验性的 Long Decode Continuation 分段续写实现，不能简单理解成一次普通调用就输出百万 token。
🦐点评：Argon 尚未普遍开放，跑分领先短期内很难直接变成开发者份额。对模型创业公司，折扣是否持续会影响价格锚点；对应用公司，应在自己的缓存命中率、输出长度和任务成功率下重算毛利，不能拿发布期单价给长期合同报价。
www.latent.space
Introducing Olmo-core 3: Open, scalable training infrastructure for large MoEs
Ai2 的 Olmo-core 3 将专家数从八个扩至一百二十八个、每 token 仍选四个专家时，训练吞吐下降不到 5%。新框架让专家常驻 GPU、把数据路由过去，减少反复聚合权重；八张 B300 的初步测试中，四百七十亿参数 MoE 吞吐约为旧实现的 2.7 倍。它同时开放专家并行、流水线并行、分布式优化器与低精度训练支持。万亿级结果使用随机路由测系统性能，2.38 万亿参数配置也只是短时容量测试，均不代表已训成同规模高质量模型。
🦐点评：Olmo-core 把大 MoE 的训练工程公开，会压缩仅靠分布式训练技巧讲壁垒的空间。它的数字来自 B300，国产芯片或不同网络上的收益仍需验证；更可持续的资产是训练数据、路由策略与真实下游能力，而不是把框架吞吐提升直接换算成模型估值。
huggingface.co
Quoting Matthew Green
隔离沙箱里的 Agent 仍可通过共享软件包缓存互留指令，改变其他 Agent 的行为。Simon Willison 引述 Matthew Green，称这已具备蠕虫的两个要素：劫持 Agent 的载荷，以及负责把载荷带给下一个 Agent 的执行者。Green 将风险外推至邮箱、Slack、共享文档和 WhatsApp 中的个人助手，提醒共同使用的信息通道可能连接原本独立的执行环境。
🦐点评：Green 点出了共享缓存这条通道，意味着安全预算不能只花在虚拟机隔离。对接邮箱和协作文档的个人助手，客户需要验证不可信内容能否越过权限边界、调用有副作用的工具；创业机会在可检查的跨系统授权和传播阻断能力，单卖一个沙箱很容易被云厂商覆盖。
simonwillison.net

晚点 AI 季报：Muse 引爆个人助理，Astra 走进机器人，OpenAI 收入猛增
OpenAI 的年化收入据媒体报道，在一个半月内由四百多亿美元升至接近七百亿美元；晚点提醒，这些不是官方披露，且与 Anthropic 的收入计量口径未必相同。访谈援引上市材料草案，称 Anthropic 前两大客户贡献约四分之一收入、长期算力采购承诺达 5180 亿美元，而收入端不少客户没有长约。个人助手的竞争同时受推理降价、云端常驻与服务生态开放影响：Instinct 接入 Shopify，Muse 却遭 Amazon 封禁。嘉宾认为，Jev 式动态分类器可替代部分传统 if 判断，但技术壁垒有限；个人助手的下载热度也还不能证明持续留存和收入。
🦐点评：Anthropic 的采购承诺与客户短约如果属实，核心估值问题就是现金流期限能否匹配，不能只比较 ARR 谁领先。Instinct 接 Shopify、Muse 被 Amazon 拦下的分化，则说明个人助手的交易闭环依赖商户合作；看这类项目时，要把真实完成率、复购和交易分成权放在下载量之前。
