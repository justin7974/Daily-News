How Anthropic’s Dynamic Workflows Coordinate Claude Agents
Anthropic 的 dynamic workflows 让 Claude 自己编写调度程序，拆分任务、启动子 Agent 并汇总结果，开发者不再必须预先配置完整队伍。AI Engineer 纽约工作坊以股票观察名单演示分阶段扫描与复核，也展示了 Console 中可追查的任务关系。讲者承认示例中的多 Agent 方案成本明显更高，运行中的模型并不知道剩余预算，开发者需在会话层设限。记忆整理功能 dreaming 可辅助复用经验，但自动识别扫描缺陷并修改下一次任务，并不是内置能力。
🦐点评：Anthropic 已把任务编排纳入托管服务，单靠“多 Agent 调度”卖软件会更难；创业公司的收费依据要转向行业数据、可重复的任务成功率，以及比单 Agent 多花的钱能否换来客户认可的结果。
www.latent.space
Andreessen Horowitz, General Catalyst Race to Secure the Chips Their Startups Need
VC 正把算力供给纳入对创业公司的支持：The Information 公开导读称，a16z 在两年前建立两万张 GPU 的集群后，正洽谈扩大服务，可能借助两家已投资的数据中心公司。报道同时援引知情人士称 General Catalyst 正建设数据中心，为组合公司供应算力。其他基金也通过经纪商寻找紧缺芯片。完整报道受付费墙限制，这些计划的规模、定价和具体条款不可获取。
🦐点评：a16z 与 General Catalyst 把服务器纳入投后服务，会让没有算力供给能力的基金更难争取模型项目；但用自建机房吸引交易，也把设备折旧和利用率风险带进了基金业务，不能把融资优势直接当成项目经济性。

OpenAI’s Plan To Revive Sora
Sora 可能通过面向电影制作人的创业公司恢复商业使用，而非直接重启原来的消费应用。The Information 公开导读称，一家由 Jeffrey Katzenberg、前 Sora 研究负责人 Bill Peebles 和前 Dropbox CFO Sujay Jaswa 创办的公司，正与 OpenAI 洽谈获取 Sora、修改模型并销售相关软件或服务。导读回顾，OpenAI 此前削减高耗算力项目时停掉了 Sora 模型和类 TikTok 应用。公司名称、授权条款及最终能否达成协议尚不明确，完整报道不可获取。
🦐点评：Katzenberg 带来的制片渠道可能比模型新榜单更影响这家公司的收入；若采用授权路线，投 AI 视频工具就要问清楚客户关系归谁、模型方能否收回供给，以及毛利能否覆盖长视频的多轮修改。
www.theinformation.com
How Meta designed Muse: an AI agent people actually want to talk to | Alex Cornell (Design Director)
Meta Muse 的设计重点，是让普通用户和工程师能用同一个聊天界面完成任务。公开节目介绍称，它用三层状态展示提供不同深度的过程信息，并通过角色形象、个性化建议和生成式信息流呈现结果。Alex Cornell 的演示包括把 Instagram 收藏变成购物目录、记录高尔夫表现，以及把旧博客做成晨间播客。节目也讨论主聊天与侧边聊天的使用分工；本次获取的是节目介绍和演示目录，未获取完整访谈逐字稿。
🦐点评：Instagram 收藏变成购物目录，说明 Meta 可以直接把既有兴趣记录变成 Agent 的起点；独立个人助手若还靠用户手工搬运偏好，会在首次使用就吃亏，能否取得用户已有数据比多做几个聊天功能更值得问。
www.lennysnewsletter.com
Software engineers don't get to be Luddites about AI
Sean Goedecke 认为，软件工程师长期以自动化其他行业的劳动创造价值，如今自己的技能被自动化时也应面对同样的变化。他用 VisiCalc 对记账工作的影响，以及纺织机械制造者后来也被更低成本劳动替代的历史作对照。作者支持认真讨论技术的社会后果，但认为仅在本行业受影响后反对自动化，立场并不一致。这是一篇职业与技术观念评论，没有提供工程师就业或 AI 编程生产率的新统计。
🦐点评：Goedecke 提到 VisiCalc 的例子，让 AI 编程工具的付费问题更具体：开发者可能反对职业替代，却仍会购买能减轻眼前负担的工具；判断增长时应区分个人省时需求和企业实际缩减开发成本，不能把二者混算。

3000万美金种子轮，红杉美国领投，让普通人也能像对冲基金一样交易
Catalyst 据报道获得 Sequoia 领投的三千万美元种子轮融资，想把用户的自然语言投资判断变成可回测、可执行的交易流程。深思SenseAI 综合投资方文章、Fortune 和官网材料称，涉及资金的执行需要用户确认，产品目前仍处于研究预览及候补名单阶段。公司自述重度交易用户试点约两周产生数亿美元交易量，但没有披露用户数量和收入，官网演示也不代表真实业绩。产品当前免费，收费方式、普通用户表现，以及法币提现的完整支持情况仍待后续验证。
🦐点评：Catalyst 用交易量证明早期需求，但免费试点和重度用户都可能放大这个数字；更该看多少用户反复启用策略、每次执行后的差错处理成本，以及未来收费会不会鼓励用户过度交易，这些才决定收入质量。

Muse Wonder 发布：Llama4 之后，Meta 再回舞台
Meta 发布 Muse Wonder 与 Muse Wonder Full，把长期记忆和遇到障碍后持续尝试列为重点能力。赛博禅心转述官方材料称，Wonder 提供 API，Full 仅供 Muse Code 的两档订阅使用，基准成绩主要来自厂商披露。文章列出的 Wonder API 标价为每百万 token 输入4美元、输出20美元，与文中列出的 Claude Opus 5.5 标价相同，虽引用 Wang 称会显著低于头部模型价格。跨对话记忆、长期编程和生活任务演示已被重点展示，独立真实任务测试仍不足。
🦐点评：Wonder Full 留在 Muse Code 订阅里，表明 Meta 也想把最强能力用于争夺应用收入；模型榜单只是获客起点，开发者是否愿意为长期任务另付一份订阅，以及企业能否直接调用最强模型，会影响独立编程工具的竞争空间。
赛博禅心
对话丘成桐：数学家与一个功利时代
丘成桐把基础研究的长期环境放在人才、奖项和短期回报之前，主张让年轻学者真正追求问题本身。晚点访谈中，他区分“给出证明”与“形成数学理解”，认为 AI 尚不能原创有意义的问题和新概念，这属于他的判断。与此同时，他承认 AI 会提升数学学科，并担忧国内研究者使用先进工具的差距与获取限制。对海外人才回流，他强调要提供可继续研究的环境，还需处理家庭、医疗和子女教育等实际问题。
🦐点评：丘成桐既怀疑 AI 的原创概念能力，又承认工具获取差距，这两件事可以同时成立；看 AI for Science 团队，应分别评估它能节省多少验证工作、是否真正提出新问题，以及有没有长期留住领域专家的研究条件。
