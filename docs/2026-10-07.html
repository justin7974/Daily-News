Advancing computer use with Ironclad
OpenAI 与 Ironclad 的合同工作流评测中，GPT-6 Astra 的平均评分为 55.0%，高于 GPT-5.6 Sol 的 41.6%，估算单次耗时由 37.0 分钟降至 19.2 分钟。双方把合同、采购和审批配置整理成 11 项研究任务，每项按 8—50 个条件评分，并提供可练习的软件环境。训练资料来自过滤后的公开 SEC 合同及合成任务，未使用非公开客户合同。结果只覆盖这些研究任务，耗时为模拟估算，不能当作客户实际节省时间。
🦐点评：Ironclad CTO Sunita Verma 强调业务控制必须贯穿合同全流程；垂直软件公司的研究资产可能是可执行的业务规则与验收环境，但把这些资产交给基础模型后，也要重新判断谁拥有客户预算和定价权。
openai.com
What is Codemode
Pi 1.0 用 Codemode 接入 MCP，让模型以 JavaScript 组合工具调用，而无需把所有工具定义和中间结果塞进对话。Armin Ronacher 将它与 Bash 区分：Bash 操作执行环境，Codemode 则在 Agent 控制程序内的独立沙箱运行，能够协调子代理、图片和分类模型。按需发现工具、批量处理和保存中间状态，都是文章展示的实际用法。作者同时指出，MCP 返回结构不稳定、大型二进制数据支持不足和调用恢复，仍会限制这一方式。
🦐点评：Ronacher 特别要求 MCP 提供稳定的结构化返回；只靠整理工具目录的产品容易被 Agent 平台吸收，企业愿意持续付费的更可能是版本兼容、执行记录和失败恢复，这些才决定工具能否承担生产任务。
lucumr.pocoo.org
[AINews] Reflection Beam - 501B-A23B American Open Model
Reflection 预告首个模型 Beam：文本 MoE，总参数 5010 亿、激活参数 230 亿，面向编程、Agent 与科学任务，并计划本月以 Apache 2.0 发布权重。Latent Space 汇总的团队说法包括 23.8 万亿预训练 token，以及超过一亿次强化学习任务尝试。其能力大致对标 GLM-5.2，仍落后于文中列举的数款中国前沿开放模型。所谓三至四倍推理效率优势来自公司比较，权重、技术报告及实际服务成本仍待进一步检验。
🦐点评：文章转述 Reflection 每月支付 1.5 亿美元算力费用，还另签 Nebius 合同；如果模型能力并非第一，估值就要靠美国来源、私有部署和主权客户的真实订单支撑，不能把融资规模直接当成技术领先的证据。
www.latent.space
Credit Crunch
Ed Zitron 把 AI 基建风险归结为信用条件：长期算力承诺很大，融资却可能越来越贵。文章以 Oracle 相关数据中心债券折价和部分银行收紧项目贷款为例，讨论融资成本如何传到云商与模型公司。作者进一步推演，持续亏损的模型公司即使上市，也未必能取得足够便宜的债务来履行承诺。其关于融资缺口、信用评级及行业崩溃的结论带有强烈看空立场，不能视为已经发生的事实。
🦐点评：Zitron 引用 Apollo 的现金流预测，质疑科技公司的增长能否由客户付款支持；对算力项目做压力测试时，要把最终付费企业、模型公司和云商逐层连接起来，同一批客户的需求不能被重复算成三份独立订单。
www.wheresyoured.at
The Cyber Risk Discourse is Broken
Nathan Lambert 认为，只禁开放权重模型未必降低网络风险，反而可能削弱防御方获得强模型的能力。文章以 Anthropic 对 GLM-5.3 的安全研究为起点，指出闭源 API 的保护也不完善，而隔离网络往往只能部署本地模型。他主张同时比较攻击能力、模型获取方式与防御扩散，讨论发布前安全评估应投入多少资源。对中国模型厂商风险取舍的解释，以及风险会渐进上升而非突变的判断，均属作者观点。
🦐点评：Lambert 提到敏感政府机构需要在隔离网络部署模型，这让安全采购有别于普通聊天产品；投防御 Agent，应先确认客户能获得哪些模型、能否在本地更新，以及模型授权变化会不会直接中断交付。
www.interconnects.ai

a16z 最新消费洞察：AI 的付费机会，藏在流量外
a16z 新榜单中，消费者 AI 支出前五十名有二十九家公司没进网页或移动流量榜；数据来自美国个人消费样本，不能当作全球营收。文章进一步检查 n8n 的工作流计次、fal 的生成计费，以及 Suno、ElevenLabs、Plaud 如何围绕实际制作与处理任务收费。对于个人 Agent，文中引用 Instinct 创始人的年化交易额说法，并明确区分交易额与平台收入。报告当时 Instinct 和 Muse 尚未收取相关交易费用，流量、支付规模与已验证商业模式仍是三件不同的事。
🦐点评：Newin 特别指出 Plaud 支出排名没有区分硬件与订阅；比较这类产品时，应把一次性销售、续费和推理成本分开，同样的消费者账单规模，可能对应完全不同的收入质量与估值倍数。
有新Newin
喝点VC｜a16z合伙人谈AI与消费：好产品要让用户"停止做某件事"，信任是AI产品进入主流的分水岭
Josh Elman 判断消费 AI 产品是否成立，首先问用户开始使用后，停止做了哪件旧事，而不是只问是否愿意尝试。访谈认为早期用户可以先接受实用性，但进入主流市场需要信任，个人 Agent 应先把少数任务做好，再扩展服务。推理带来持续变动成本，免费获取用户之后仍要找到合理收费方式。Elman 同时看好个人 Agent、互动娱乐和语音，但强调长期留存需要关系、历史信息或共同使用形成的价值；本文为访谈编译。
🦐点评：Elman 描述购物助手时，要求其激励与买家一致；这对交易佣金模式提出直接约束：若推荐排序由佣金决定，短期收入可能伤害长期委托关系，尽调时应把推荐机制和留存数据放在一起看。
