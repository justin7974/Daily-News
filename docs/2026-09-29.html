AMD to Buy Fei-Fei Li's World Labs for $8.2 Billion
AMD 周一宣布以约 82 亿美元全股票交易收购成立仅两年的 World Labs，后者专做可模拟三维空间的模型，交易预计今年底完成。World Labs CEO、AI 研究者李飞飞将加入 AMD 出任执行副总裁兼首席科学家，直接向总裁汇报。据知情人士，a16z 是 World Labs 最大股东，持股近 14%。
🦐点评：82 亿美元的价签本身不是重点，重点是 AMD 承认"只卖算力"不够——它要把空间智能（世界模型）纳入自家产品栈，这是对英伟达在仿真/机器人数据上游布局的正面回应。对 VC 的意义在于，世界模型这条线第一次出现英伟达系之外的第二家芯片巨头作为既定退出通道，Space Intelligence 类早期资产的估值锚被抬高；而 a16z 近 14% 的持仓意味着，这笔全股票交易同时是"芯片公司给纯研究资产定价"的公开样本，值得拿来校准同类项目。

OpenAI Will Not Ship GPT-6.1 Astra Due to Safety Concerns
据 OpenAI 发言人周一证实，公司决定不发布原本计划命名为 GPT-6.1 Astra 的模型，原因是其在一系列安全测试上的结果不达标。该模型在衡量"追逐特定风险行为"的测试中，表现比本月初刚发布的 GPT-6 Astra 更差——也就是说，迭代版本反而在安全维度上回退。
🦐点评：这是"能力提升"与"安全可控"第一次公开脱钩的标志性事件：一个被内部定位为升级版的模型，因为安全测试回退而被直接按下。结合同日佛罗里达要求暂停 ChatGPT 开发、以及英伟达拉 100+ 伙伴做"Agent 安全平台"，可以判断前沿实验室正在把"发布节奏"让位于"可解释性/可控性"，这会抬高头部实验室的合规成本，却也构成对后来者的护城河。要盯的是：Astra 是被永久搁置还是回炉重训，以及 OpenAI 是否会把"安全回退即不发布"写进合同级别的模型发布流程。

Claude Sonnet 5.5
Anthropic 发布新模型 Claude Sonnet 5.5，官方称"速度快 30%+、多数工作成本降最多 30%"，定价与 Sonnet 5 相同却在几乎所有基准上更好。Simon Willison 的实测观察是：Sonnet 5.5 已是 claude.ai 免费档所用的模型，而 OpenAI 的 ChatGPT 免费档用的是 Luna 5.6——这意味着当前 Anthropic 的免费层能力明显更强。他同时记录了一个 bug：在 "max" 思考档位下模型为画一只骑车鹈鹕耗掉 12.8 万 token（花费 1.28 美元）仍未产出 SVG；Haiku 5.5 官方称"未来数周"上线。
🦐点评：真正值得记一笔的不是那 30% 的提速，而是"免费档位"成为新战场——Anthropic 把接近旗舰的 Sonnet 5.5 直接下放到免费层，是用前沿能力换用户规模，这对仍在按 token 计费的二线模型是降维打击。另一层信号是 Willison 点的成本-可靠性问题：同一模型在"高强度思考"下会烧掉远超预期的 token 仍失败，说明推理档位与实际任务之间还没有稳定的映射，谁先把"该想多久"做成可靠的自动策略，谁就能在企业级推理定价上占先。

Holo4: powering generalist computer-use agents
Hcompany 开源新一代 agentic 模型 Holo4，含 27B 稠密版与 35B-A3B MoE 版，同一模型即可通过 GUI、代码、MCP 和 API 四种接口操作软件，覆盖桌面、网页、Android、代码沙箱与业务 API。在最难的桌面控制基准 OSWorld 2.0 上，Holo4 27B 得 61.7%，对比 Opus 5.5 的 81.8%；35B-A3B 为 30.9%，但以数量级更少的参数和显著更低的单任务成本运行。模型经监督学习与强化学习在"Agentic Task Factory"生成的环境上训练，团队开源了所有基准轨迹。
🦐点评：Holo4 的价值不在刷榜，而在把"多接口通用 agent"从闭源旗舰专属变成可自托管的开源权重——61.7 分对 Opus 的 81.8 分看着差距不小，但换算到"每任务成本"上，闭源模型的定价权会被明显压缩。对 VC 的启示是：computer-use 的护城河正从模型能力转向"环境与轨迹数据"，Hcompany 选择开源轨迹而非只放模型，等于在抢训练数据的标准制定权；真正会被动摇的是那些靠"通用 GUI Agent"讲高价故事的公司。

OpenAI Understands Something Important and Rare
a16z 的 David George 提出，OpenAI 会赢不是因为它模型最好、芯片最强或成本曲线最优，而是因为它最擅长"创造新种类的客户"并拥有最耐久的渠道。他列了四条护城河：创造新行为、分发、定价捕获价值、高切换成本——指出在模型层切换成本（第 4 条）已基本失效（可任务级换模型），定价（第 3 条）最终属于规模化领先者，所以胜负实际由"创造新行为"和"分发"决定。文章把 ChatGPT 称为一场"幸福的意外"，并引述 Thiel 当年劝 Sam 的话："你已经创造了一种新客户。"
🦐点评：这篇是当下少见的、把"模型能力不重要"讲清楚的反共识框架——如果切换成本已失效、价格战又只奖励规模，那么所有还在用"我们模型更强"做融资叙事的应用公司都站不住脚。真正的启发是：投资人应该把问题从"谁的模型好"改成"谁在唤醒一种以前不存在的消费行为"，这恰好解释了为什么 Manus Cue、Meta Muse、Fo 这类带独立邮箱/电话/钱包的"个人 agent"在抢着定义新入口——入口即新客户，新客户即分发权。

斯坦福团队将 LLM 后训练思路引入机器人，VLA 开始从真实经验中继续学
斯坦福博士生 Perry Dong 与导师 Chelsea Finn 发布长文《Towards Universal Post-Training for Robotics》，提出机器人基础模型正处在"GPT-2 时刻"：VLA、世界-动作模型等预训练已能完成复杂任务，但"会做"与"可靠地做"之间仍有巨大鸿沟（一个 95% 成功率的机器人，剩下 5% 在玻璃制品、宠物与孩子环绕的家庭里足以不断制造事故）。他们主张机器人缺的正是语言模型已经走通的那套后训练路径——足够强的预训练底座 + 明确定义的环境与奖励 + 成熟的 RL 算法 + 对 reward hacking 的监控，只是机器人需要专为其十亿参数规模设计、且能从极少真实经验中学习的算法，以及定义成功/复位/人工介入的协议。
🦐点评：把"机器人 = GPT-2 阶段"这个类比当真，投资动作就完全变了——当前 VLA 公司的估值锚应该看"数据采集与后训练基础设施"而不是模型榜单，因为稀缺的不是会演示的模型，而是把"偶尔成功"变成"稳定可靠"的配方和协议。这也解释了为什么英伟达、DeepMind、Physical Intelligence 都在抢同一件事：谁能定义机器人的后训练标准，谁就握住这条供应链的收费站；而"真实样本昂贵、难以并行验证"这一点，恰恰是纯软件 RL 玩家无法平移过来的壁垒。

Manus 2.0 发布，重启国内市场
Manus 发布 2.0，最底层换用自研 Agent 框架 Cascade：在官方一项测试配置中，token 消耗较上一代减少 23.2%、任务完成时间缩短 28.2%、运行成本降低 32%（同一配置，非整体平均），思路类似 Skill 的按需加载，项目内简报、页面、视频与自动化流程始终关联。桌面应用升级为 Manus Studio，新增视频编辑器与游戏开发两个专业环境，并支持在手机上让 Manus 操作电脑；同时推出面向个人生活场景的新应用 Cue。2.0 还可单独购买"云电脑"作为常驻运行环境，原有的定时任务升级为由邮件、广告数据、日历、Slack、Notion 等事件触发的 Automations。报道称 Manus 正在组建团队开发面向国内市场的产品，并与国产模型厂商及生态伙伴合作。
🦐点评：这份更新最值得记的不是功能清单，而是成本数字——Cascade 把 token 成本砍掉约三分之一，说明"个人 agent"赛道的竞争已从能力演示转向单位经济模型，谁先把长任务的 token 烧钱量压下来，谁才有资格谈订阅定价。更关键的是"云电脑 + 事件触发"这套组合：它把 Manus 从"你打开才干活"的对话工具，变成一台常驻在线、由外部事件驱动的虚拟员工，这一步跨过去，agent 就真开始占用"人头预算"而非"软件预算"；Cue 出海抢 Meta Muse 的地盘、国内重启，则是同一套框架复制到两个市场的双线下注。

深度｜只用2周完成模型升级，最适合应用公司的后训练平台来了
Mind Lab 发布模型后训练与推理平台 Mint Recursive，并同步以基于 GLM5.3、仅用两周完成的后训练模型 Macaron V1.1 做演示。文章的核心观察是模型研发正从"交付项目"变成"持续更新"：Cursor 用真实用户反馈训练其编程模型 Composer，最快每五小时推送一个新 checkpoint。真正稀缺的资源不是基座模型，而是企业自己的判断标准——Bridgewater 旗下 AIA Labs 与 Thinking Machines 的实验显示，仅优化提示词很快触顶，加入投资专家筛选/标注数据后模型判断才显著改善。而这些判断藏在专家的选择与用户的接受/拒绝中，因此企业更现实的目标是拥有一个可控可更新、并保留业务判断的模型版本。文章指出，持续训练的真正瓶颈是基础设施：训练、推理、任务环境必须协同，训推不一致会让系统把误差误判为进步或退步。
🦐点评：这篇文章点破了一件容易被忽略的事——"后训练平台"本质上是企业私有数据的操作系统，它的价值不在算法，而在能否把散落在专家选择里的隐性标准稳定地固化进模型，同时保留更换基座的自由。对 VC 而言，这是"中间层"里少见的、能讲清楚护城河的资产：谁掌握"训推一致"的工程细节和反馈闭环，谁就锁定应用公司的长期预算，因为一旦企业把判断标准沉淀在某套平台里，迁移成本极高。Cursor 每五小时一个 checkpoint 的节奏也说明，未来应用公司的竞争力指标会从"模型多强"变成"发现问题到重新上线的周期有多短"。
