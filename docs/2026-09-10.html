[AINews] OpenAI reports Navier-Stokes singularity find in 88 hours using Astra-next, roughly 10,000 agents and 130B tokens (>$40M)
OpenAI 宣称用一个"明显强于 GPT-6 Astra"的下一代模型、约 1 万个 agent 协作，攻下了纳维-斯托克斯千禧难题，这条消息把同一天的一堆重磅融资全部盖过——Cognition 的 480 亿美元 E 轮、Mistral 的 240 亿美元 D 轮、Meta 把 Dreamer 重启为 Muse agent、GPT Image 2.5，放平时每条都能上头条。据参与者 Ethan Knight，OpenAI"过去一年"专门训练模型用多智能体强化学习协作，押注难题可以靠"大规模无结构的并行 test-time compute"、让模型自己决定怎么组织。但社区对真伪和署名吵翻：广为流传的"88 小时"只出现在一条讽刺推文里、并未证实，"solution"到底是完整证明还是研究线索也没说清，数学界当时远未完成验证。
🦐点评：一天之内 480 亿(Cognition)加 240 亿(Mistral)两轮巨额融资被一条数学新闻盖过，这个"被盖过"本身才是信号：资本已经把编码 agent 和前沿实验室的定价推到只有"AI 能做科研"成立才撑得住的位置。而"1 万 agent、130B token、单次跑 4000 万美元"把壁垒从模型权重挪到了谁烧得起 test-time compute——这是个 capex 游戏，结局是除了有超大厂算力兜底的实验室，其他人连入场券都买不起。对基金的操作含义：投"并行推理编排/agent 调度"这层卖铲人，比赌哪个模型最终赢更稳。

Investing in Cognition
Marc Andreessen 宣布 a16z 投资 Cognition，核心论据是一个数字：一年内 Devin 写的代码从占 Cognition 自身生产代码的 13% 涨到 90% 以上。他把"软件以人手速度吞噬世界"改写成"以算力速度吞噬世界"——过去十五年全球前十大公司里科技的市值占比从 31.5% 升到 94.4%，而这还是在"每 300 人才 1 人写代码、且每行都靠手写"的前提下发生的。文中给了几个落地案例：奔驰把原本 8 个月的 COBOL 迁移用 Devin 压到 8 天，Rivian 测试生成提速 10 倍，巴西 Itaú 银行 70% 的安全漏洞由 Devin 自动修复。Scott Wu 的说法是工程师会"从砌砖的变成设计系统的架构师"。
🦐点评：这既是投资公告也是 a16z 给 Cognition 480 亿估值背书的叙事工程——用"生产代码占比 13%→90%"这种可量化指标定基准，等于逼所有编码 agent 组合公司都拿出同类数据来对标。真正该警觉的是定价范式：如果工程师变成"指挥 agent 舰队的 CTO"，按人头收费的 SaaS 逻辑就崩了，价值会沉淀到掌握编排层的一方。对看应用层的基金，奔驰 8 个月→8 天这种案例说明卖点已从"提效"变成"吃掉整条外包/迁移预算"，该被重估的是那些靠人力套利的 IT 服务商——它们是这波最直接的被拆迁户。

GPT-6 Astra: The next generation in intelligence for work
OpenAI 发布面向工作场景的旗舰模型 GPT-6 Astra，官方主打更强的推理、computer use（自主操作电脑）以及写作和设计判断力，定位是"最能干企业活的模型"。从这两天的使用反馈看，它的 computer use 让不少非专业用户第一次靠一句话指令驱动 Blender、做出可用的 3D 场景，这类"看得见成品"的案例在网上快速扩散。而据 Latent Space，OpenAI 用于纳维-斯托克斯攻关的其实是一个"明显强于 Astra"的未发布下一代模型——说明 Astra 之上还压着更强的牌。
🦐点评：Astra 把定位从"聊天"挪到"干活"加 computer use，等于 OpenAI 正面切入企业 agent/RPA 和白领工作流这块最大的 TAM，Salesforce 式的软件和外包都在射程内。更该注意的是它"藏牌"——真正攻数学的是 Astra 之上的未发布模型，这种刻意的能力过剩(capability overhang)对应用层创业者是持续威胁：你今天在前沿模型上建的护城河，可能下一次发布就被抹平。给基金的操作：投应用别赌"现在能力有差距"，要赌"即便底座能力再翻倍你仍然值钱"的公司——数据、分发、工作流锁定，而不是套壳。

When will average people feel AI's impact?
Nathan Lambert（休完婚假回归）泼了盆冷水：AI 对普通人的日常仍是"一个四舍五入可忽略的量"。他的论点是，把这轮 AI 类比工业革命只对了一半——规模上像，但普通人接触不到任何"实实在在的新商品"，而且今天社会抵抗变化的惯性比过去大得多。家庭、饮食、交通、娱乐这些生活核心几乎没被触及；正面接触点是"做点好玩的图、增强版搜索"这类小恩小惠，负面则是把 AI 和上瘾算法、数据中心联系在一起。他自己婚假期间唯一用到 AI 的，就是搜索和给婚礼做座位图。
🦐点评：来自前沿实验室内部人的降温值钱，因为它能校准出手节奏：如果 to-C 端根本没有"摸得着的新商品"触点，那近两年的真实价值几乎都在 B2B/生产力侧，而消费级 AI 应用是在抢"做点好玩的图"这种留不住人的边际效用。更关键的推论是——瓶颈在扩散和惯性，不在能力。这把优势交回给掌握分发的在位者、而非只有能力的创业公司，所以对"又一个套模型的 to-C app"该更谨慎，对能嵌进现有工作流/渠道的反而加分。
interconnects.ai
Quoting Terence Tao
陶哲轩（Terence Tao）的一段话被 Simon Willison 摘出：好的、有产出的开放数学问题正在被"以不可再生的方式开采"，可能走向枯竭。他点出一个新机制——如今"哪怕只是有人在做某个问题的传闻"，都会触发大规模 AI 算力去抢在原研究者完成前把它"压平"。他担心这会把激励导向"不再向社区分享任何有前景的研究方向"，从而逆转数百年的开放科学传统、对整个领域造成长期伤害。
🦐点评：这是纳维-斯托克斯事件的二阶成本，而且可投：如果 AI 把开放研究变成"谁先算出来谁赢"的圈地，那么其一，算力可及性会成为科学 IP 的硬约束，利好握有最大集群的一方；其二，规范会从"公开"转向"保密"，反而催生私有研究/IP 保护工具和封闭数据护城河的市场。对 deep-tech 基金，Tao 说的"不再分享研究方向"意味着未来最值钱的科研资产会越来越早被藏起来，尽调里"开放 benchmark 领先"的说服力在下降，而"私有数据+私有算力"的组合在升值。

🔥 精选推荐

Astra 的 Computer Use 能力是如何实现的？
这篇编译自 Browserbase 增长工程师 Kyle Jeong 的博客，拆解了 GPT-6 Astra 的 Computer Use 怎么做出来：Codex 启动一个常驻代码环境、接入浏览器和桌面工具，Astra 用无障碍模式读取界面的文字与按钮结构、再结合截图综合判断，把要执行的操作写成代码交给 Codex 完成。它对比了 2024 年以来的纯视觉路线（Claude 3.5 Sonnet、OpenAI Operator、Gemini）的两大局限——后训练绑死了固定视口尺寸、换窗口就点不准，且"只靠眼睛"看不到复杂交互。Astra 训练中融入大量专业环境并用 RL 改进策略选择和纠错，因此能用更少交互完成同一任务。作者判断 Computer Use 让 agent 覆盖更多白领长尾场景，会把 token 消耗和渗透率再推一个台阶。
🦐点评：对基金，真正的信息是架构换代：从纯视觉转到"无障碍树+代码执行(Codex harness)"，说明 computer-use agent 的护城河在 harness/环境工程，而不只是模型——这和 adaption_ai"丢分在 Harness"的结论互相印证，卖铲机会在环境/工具层。其次它点破了 GTM：Astra 的出圈靠"房产从业者看到别人用 Blender 做 3D 就想接自己的房源"这种可代入案例，而非 benchmark 分数——所以评估这类公司要看"能不能制造可复制的 aha 时刻"和 token 消耗曲线，而不是刷榜。
海外独角兽
大模型的空间直觉从哪里来，又为什么会失灵？MirroS在S-Space里找答案
MirroS 的 S-Space 工作给多模态模型的空间推理一个更细的解释：模型内部其实已经形成了相当准确的"空间地图"，真正薄弱的是稳定地读取、变换和使用它。研究者能从中间层直接读出物体沿水平/垂直/距离三个方向连续编码的坐标，还能人为改写坐标并观察到空间判断随之改变——把"空间智能"从输出层的表现变成可观测、可诊断、可外接计算的内部结构。最关键的发现是把空间推理拆成"感知"和"操作"两层，瓶颈在视角变换：以 Qwen3.6-27B 为例，直接回答视角转换准确率 60.96%，加思维链升到 83.56%，而先从 S-Space 读坐标、再由外部程序做固定旋转并用确定性规则作答，能到 95.21%。
🦐点评：这类机制可解释性研究难得有可落地的钩子：既然地图已经在模型里、错在"读图和转向"，那实用解就是神经符号架构——LLM 读出隐状态坐标、交给外部确定性求解器，成本很低就把 60%→95%。对具身智能/机器人赛道，这暗示赢家栈可能是"更小的模型+显式空间求解器"，而不是一味把 VLM 做大；尽调时该问的是"空间能力是端到端硬刷的、还是可外接可诊断的"——后者更省算力也更可控。

实测 Codex+Astra 还是比 CC+Fable 差远了
作者用一次真实的电脑故障做了场对照实验：凌晨一堆 App 卡死、重启后触控板点得下去但指针不动，他把同样的症状分别丢给 Codex（GPT-6 Astra，ultra）和 Claude Code（Fable 5.1，high+plan）。两者读到同一段内核报错，但 Codex 用四分钟给出"安全模式→Apple 诊断→重装 macOS"的通用三步、且承认无法确定是软件还是硬件；Claude Code 花十六分钟直接定位到触控板传感芯片(AFE)在 macOS 侧启动握手失败、HINT_L 是芯片级握手线，建议彻底断电静置两分钟以上。作者按 CC 的建议关机静置，触控板直接恢复——若按 Codex 的建议可能白白送修。
🦐点评：孤例不能证明谁强，但对做开发者工具的基金，信号在"模型+harness"的分化：Codex/Astra 在读到报错前就检索好了"安全模式→重装"的通用套路、图快，CC/Fable 则在 plan 模式下推理到芯片级根因。启示是——在高风险、长尾的诊断任务上，"带规划的深度推理"比"秒回"更值钱，而这恰恰是编码 agent 走向同质化后还能拉开差距的一条轴。谁把 harness（规划、工具、校验）做深，谁在这类任务上就有可辩护的溢价。

主观评价字节阿里腾讯之Agent大战
一篇主观评价办公 Agent 走向的文章，抛出两个判断。其一，形态会收敛成"本地客户端+对话框+手机 App 操控电脑"，说白了就是抄 Codex——作者认为程序员并不爱用 IDE，对话框这种极简形态才是普惠大众的方向，Qoder 改版成对话框、阿里把 Qoder Work 并入千问办公都是佐证；他也直接反驳"不该再投 GUI 思维软件公司"的说法，认为 AI 要普惠就得 GUI。其二，软硬一体，录音卡会是办公 Agent 的重要入口，钉钉、飞书几乎贴钱卖录音卡是在铺基础设施、积累完整 Context，而独立录音卡（如 Plaud）在中国难有独立市场。
🦐点评：对看中国 AI 的基金，这张办公 Agent 战场地图比它的口水味更有用："形态收敛成对话框、组织必须收敛到一个入口"直接推出整合逻辑——阿里把 Qoder Work 并入千问办公、春节补贴战不可能同时投两个 agent——于是可持续的价值不在 App 界面，而在数据/上下文护城河，这正是钉钉飞书贴钱铺录音卡去圈的东西。可操作的结论是：押注掌握"硬件采集→上下文闭环"的一方（飞书/钉钉），对没有分发后端的独立 AI 硬件（Plaud 式）保持警惕。
