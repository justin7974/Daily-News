Anthropic 把 Agent 会话与执行沙箱分离，争夺开发运行平台
Anthropic 的 Managed Agents 将会话记录和 harness 与执行代码的沙箱分开，沙箱故障不必让整个任务丢失。平台工程负责人 Katelyn Lesse 和产品负责人 Angela Jiang 介绍，服务凭据由独立代理附加，生成的代码所在沙箱无需持有凭据；网络访问也受到控制。此前把整个 Agent 塞进沙箱的方案，启动延迟和故障恢复成本更高。访谈还介绍由一个 Agent 检查另一 Agent 的历史工作、写回记忆的实验，部分平台构想仍属路线计划。
🦐点评：Claude 把持久会话、执行隔离和凭据管理一起提供后，独立 Agent 基础设施公司会面对来自模型厂商的直接竞争。投资这类公司，要看客户是否需要跨模型迁移、私有部署或特殊执行环境；仅替单一 Claude API 补齐通用运行功能，收费空间容易被平台吸收。
latent.space
Liquid AI 发布 LFM3：约 2B 参数覆盖多模态和端侧 Agent
Liquid AI 将文本、视觉、音频、全模态和决策模型统一到一个约 2B 参数的底座，并开放权重。文本模型提供 256K context，4-bit 权重约占 1GB，六个分支模型均可用单张 GPU 微调。公司自测称，1.7B 文本模型在 WebArena-Verified 上由前代的 3.02 分升至 38.42 分；其机器人 VLA 在 Jetson AGX Orin 上生成动作片段耗时低于 50 毫秒。这些结果来自发布方，尚不能替代真实设备上的独立测试。
🦐点评：LFM3 把单卡定制和本地部署放在一起，可能削弱“微调一个小模型”本身的稀缺性。端侧创业公司要证明的是：在功耗、热限制和断网情况下仍能完成客户任务，并且掌握设备分发或独有数据；下载量和通用榜单难以支撑长期溢价。
huggingface.co
指数时间假设被否定的论文引发讨论，不能直接推导密码已被破解
John D. Cook 介绍，Anthropic 和 OpenAI 均已发表声称否定指数时间假设（ETH）的证明，并引用 Shiva Kintali 对 OpenAI 证明的简化版本。相关主张是为 3-SAT 给出次指数时间算法，并非宣布找到多项式时间算法，因此不能据此认定 P=NP。作者在评论区称 Kintali 已检查并简化证明，但没有给出全面独立核验完成的证据；他还转述了 Lean 形式化命题与论文措辞差异的讨论。现阶段应把它视为重大研究主张，继续观察证明核验和算法的实际复杂度。
🦐点评：Cook 讨论的是最坏情形下的渐近复杂度，距离可用于现实攻击的成本还有很长一段。安全公司的采购变化取决于具体算法、输入规模和运行成本，不能把 ETH 新闻直接换算成加密行业收入；AI 科研公司的价值也应由可复核成果来支持。
johndcook.com
Ai2：评判科研创意是否新颖，换几个提示词就可能翻转结果
Ai2 发布科研新颖性评测，在六个 LLM 裁判上发现提示词、推理预算和检索配置会显著改变结论。同一组人类与 AI 创意对比中，GPT-5.4 仅因提示词变化，准确率便由 93.5% 降至 40.9%。两套专门的新颖性评估系统更贵，却未超过简单提示 Claude Opus 4.6 的基线；增加搜索和推理也不保证更好。人类与生成创意数据采用部分弱标签，研究还以无需假定正确答案的判决翻转率检验稳定性。
🦐点评：Ai2 的实验说明，能生成大量研究方向和能筛出有效方向，是两种不同能力。看 AI 科研平台时，应要求跨提示词的稳定性、专家盲评和真实实验命中率；如果估值建立在模型给自己打的“新颖性高分”上，新增算力可能只是在放大误差。

Simile 用真人数据做模拟用户，关键在预测能否经得起现实检验
Simile 的商业方向是把真人访谈、问卷和行为数据变成可重复使用的模拟用户，而非只给通用模型一份人口画像。文章回顾其 7 月完成的 2 亿美元 B 轮、20 亿美元估值，属于历史融资信息；公司称 A 轮后五个月收入增至五倍，未给绝对金额。其与 Gallup 等合作渠道可触达四千多万人，CVS 项目披露使用逾四十万参与者的 290 万份授权回答。研究中的“85%”是相对真人自身前后回答一致性的比例，不能读成对所有现实行为有 85% 的预测准确率；客户用途和效果主要来自公司及投资方披露。
🦐点评：Simile 能接触真人并获得授权，才有条件持续核对模型，而不是只把“合成用户”卖得更便宜。要验证 20 亿美元估值，需要看模拟结果能否减少客户真实试错成本，以及新客群、新产品上是否仍准确；收入增长五倍而无基数，不足以判断其商业规模。

Anthropic 招股书梳理：客户扩张很快，模型更新和算力合同也很重
作者转述 S-1，称 Anthropic 2026 年上半年收入 162.86 亿美元，二季度经营利润 9.74 亿美元，但上半年仍录得 807 亿美元净亏损。文章将其中 724 亿美元归于可转债、衍生负债与 SAFE 的公允价值变动，不能把这部分当作现金消耗。其转述的净收入留存约 900%，不含订阅用户，且按同一客户群的季度支出比较；三季度超过 80% 收入来自过去六个月发布的模型版本。文中还列出多年算力采购及租赁安排，其中部分合同要求不论实际使用量都付款；以上为二手解读，上市估值和募资规模尚非确定发行结果。
🦐点评：三季度收入高度依赖最近半年的模型，说明 Anthropic 的客户扩张仍需研发持续兑现，不能直接按成熟 SaaS 的稳定续费定价。多年采购合同又把部分成本提前固定下来；看这类公司的利润，应把模型更替时的客户迁移、单位任务收入和逐年最低采购额一起算。

伊朗 AI 创业观察：国际网络中断暴露本地服务的依赖
葬AI 的实地访问及伊朗科技记者 Mehrin Nazari 的记录显示，本地打车、电商和支付可在国内网络运行，国际断网却让工程团队失去 GitHub、Docker、文档及协作工具，工作转为维持服务。受访创业者提供模型 API 和企业定制系统，并称中国模型的波斯语能力仍弱于 Gemini、ChatGPT。断网期间用户转向 Vira、MetisAI、Zigap 等本地工具，多媒体能力仍有差距。报道以个体访谈和记者亲历为主，不能据此推定伊朗 AI 市场规模或所有用户的使用情况。
🦐点评：伊朗团队能继续收本地订单，却可能因开发和模型服务依赖国际网络而停摆，这比 API 价格贵一点更影响收入。看语言和区域型 AI 公司，要分清本地分发优势与外部连接造成的短期替代需求；只有网络恢复后仍留住客户，才说明产品有独立价值。
