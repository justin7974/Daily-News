Competing ARR Estimates & Fuzzy Valuation Math in the Spotlight as Markets Get Edgy
OpenAI 被广泛引用的年化收入规模相差约 200 亿美元，Newcomer 将争议指向总额与净额口径混用，而非直接认定业务下滑。文中指出，Anthropic 把云合作伙伴销售计入总额，OpenAI 此前使用净额，简单比较容易误判双方规模。作者同时质疑分批融资只披露单一估值，掩盖不同批次的成交价格。可读部分还讨论欧美开源模型的主权定位：除敏感数据场景外，受访投资人称应用创业者更看重性能和成本。

Deno is joining Cloudflare
Cloudflare 收购 Deno，重点转向 celld 与 Workers 编程模型的自托管支持。Deno runtime 将再维护一年，提供每月错误修复与安全更新，随后停止自身开发，代码继续开源。Ryan Dahl 解释，兼容 Node.js 让 Deno 越来越像重新实现 Node，性能、体验和安全的边际优势不足以解决大问题。他更看重 celld 以对象存储协调和持久化服务器应用的新抽象。
🦐点评：Ryan Dahl 亲自放弃继续发展自己设计的 runtime，这比收购本身更有信息量：开发工具若必须兼容主流产品才能获客，技术领先很容易被兼容成本吞掉；看这类团队，应问新抽象能否改变客户的部署方式，而不只比较跑分。
simonwillison.net
Impactful scheduling for GPU clusters
Ai2 在 GPU 请求达到供给两至三倍的情况下，用时间预算、分层公平分配和可抢占合约替换原来的优先级调度。30 天观察中，各团队获得应分配 GPU 小时的 98%，集群占用率维持 98%，避免把机器长期锁给暂时没有任务的团队。小型调试任务实际 p90 排队时间从两小时降到三十秒，需要人工介入的维修减少 74%。这些是 Ai2 自报的运行结果，集群占用率并不等于 GPU 的有效计算利用率。
🦐点评：旧系统里所有任务最后都标成 HIGH，说明算力稀缺时先失灵的可能是组织激励；卖 GPU 调度软件的团队要证明它能约束占资源行为，并把节省的等待换成更快的实验迭代，单报高占用率不足以证明客户收益。
huggingface.co
I expect rapid progress but not towards general superintelligence
Nathan Lambert 预计 AI 会快速提高研究工程效率，但不把这种进步直接等同于通用超级智能。公开可读部分认为，训练速度、每次回答成本等有明确反馈的指标，更适合 Agent 自动优化，未来数年推理效率可能继续大幅提高。他将近期路径概括为并行的 AI 辅助语言模型研究，预计预训练架构与数据选择的部分研究可能在两三年内自动化。文章后段受付费墙限制，上述均为作者预测。
🦐点评：Lambert 说研究机构即使买到质量很差的 RL 环境数据，仍能看到投资回报：这提示后训练数据供应商有需求，却未必有壁垒；要分清客户在为短期缺货付钱，还是为能稳定提高任务成功率的评价体系付钱。

《State of AI Report 2026》最新洞察：模型公司开始卖交付 AI，软件产业的分工正在被改写
模型公司开始亲自承担企业部署，AI 软件的交付成本与客户关系正在重新分配。文章借《State of AI Report 2026》指出，Agent 要完成跨系统任务，还需处理权限、有效数据、人工审阅和失败恢复。其转述的实验中，同一 GLM-5.1 在不同运行框架下的 pass@1 从 52.5% 升至 65.5%，只适用于指定代码任务与实验条件。连接器、版本化流程与可重复评测有机会积累为产品，但驻场服务和人工补救不会因推理变便宜自动消失。
🦐点评：OpenAI 拟把 Tomoro 约 150 名部署专家纳入服务体系，说明模型平台自己也承认实施人力绕不过去；企业 Agent 尽调应看第二个、第三个客户是否明显少用人，若收入仍随驻场人数增长，就应按服务公司的利润结构估值。

对话 8 位汽车工程师和学者：上世纪成熟的踏板，为何今天还会断裂？
尊界 V800 刹车踏板支架在相同测试场景中三次断裂，受访工程师认为紧急踩踏应在设计验证范围内。报道区分了让车辆达到最大制动力的 500 N 要求与支架机械强度要求，避免把不同指标混为一谈。专家指出，玻纤增强塑料并非不能用于支架，但动态载荷、温度、制造批次和结构余量需要联合验证。仅凭视频与照片不能确定失效主因，仍需实物检验；车企则称已经按高于相关标准的要求完成开发验证。
🦐点评：报道提到部分机械件供应商利润只剩约 3%，并常由供应商自己出硬件测试报告：投汽车或机器人硬件时，应把量产一致性与独立失效验证当作组织能力来查，低成本和快交付可能把尚未计入的质量负债留给未来。

Anthropic 联合天文学家，完成了第一张完整的全天紫外地图
约三分之一从未被紫外望远镜覆盖的天空，由模型预测补齐，而非新增实测观测。文章转述 Anthropic 案例：Brice Ménard 使用 Claude Science 整理 GALEX 等公开巡天数据、统一定标并完成全天紫外图，输出区分实测与预测并附误差。流程还根据 Gaia 数据估算一亿多颗恒星的紫外亮度。官方称原需数周的工作缩短为数天，但中途仍由科学家发现并推动修复大气辉光残留。
🦐点评：GALEX 的残留误差穿过了两轮 Agent 审查，最后由 Ménard 肉眼发现：AI4S 的近期付费机会更可能是替专家清理长期积压的数据工程，而非承诺自动发现；产品要把专家验收和误差溯源做得便宜，才有可复制收入。
