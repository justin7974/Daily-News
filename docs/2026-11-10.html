Handshake AI 训练业务年化流水达 10 亿美元，前沿实验室购买真实工作环境
Handshake 团队称，其 AI 训练业务上线约一年，年化总收入达到 10 亿美元；这是 gross annualized revenue，不能直接等同于净收入或已确认年收入。Latent Space 的现场演示显示，金融 Agent 能解释商誉的税务规则，却在处理实际交易邮件并生成 Excel 时用错规则。生物图像任务中，模型找出两张目标切片后又多选了一张；安全评估则需要追踪文件读取与命令历史，仅看最后的答复会漏掉行为。访谈展示的供给已从问答标签延伸到专业环境、执行轨迹与专家判卷。
🦐点评：Handshake 的金融演示说明，客户愿意采购的可能是“能区分会背规则和会做业务的训练环境”。这类公司的壁垒要看专家供给、评分质量和任务持续更新；尽调时尤其应拆开 10 亿美元流水中的专家报酬、交付成本及实验室客户集中度，不能套用纯软件收入倍数。
latent.space
Amazon HOPE：剪掉一半 MoE 专家，特定编程评测接近未剪枝模型
Amazon 团队报告，在 Qwen3.5-35B-A3B 上剪除 50% 专家后，HOPE 的 SWE-Bench Pro 得分为 42.3，未剪枝模型为 41.8，同等剪枝率下 REAP 为 36.2。方法同时考虑专家之间的协作关系，避免只按单个专家的重要性删除参数；不需要再训练，也可与量化叠加。研究覆盖三个模型、两类校准数据及多项评测，优势主要出现在 40%—50% 的高剪枝率。当前方案逐层处理，跨层影响尚未充分解决，单项得分也不能推出全部能力无损。
🦐点评：HOPE 若能在客户真实任务上复现，开源推理公司的竞争点会进一步转向按任务压缩模型、分配显存和设计服务。评估这类标的，应要求同硬件、同上下文、同成功率下的每任务成本；仅凭原始模型参数大、占卡多来解释收入增长，资产回报假设可能很快过期。
huggingface.co
ChatGPT Enterprise 进入 AWS Marketplace，合资格支出可抵扣云采购承诺
OpenAI 宣布 ChatGPT Enterprise 已上架 AWS Marketplace，企业可通过现有 AWS 采购与账单关系购买，合资格支出可计入 AWS 承诺消费。Marketplace 版本提供与直购相同的模型和功能，新功能同步发布，覆盖 ChatGPT、ChatGPT Work、Codex 与 dots。该产品与 Amazon Bedrock 内的 OpenAI 模型形成不同采购入口，适配业务用户和应用开发者。医疗与金融行业版本也向合资格客户开放，具体资格仍需向双方确认。
🦐点评：AWS 承诺消费可抵扣，意味着企业比较 AI 工具时，会同时比较预算来源和采购便利度。独立办公 Agent 若还需客户新开预算、单独走法务和安全审查，即使功能更好也可能输在成交周期；投这类公司时，应把渠道上架和存量软件预算迁移能力纳入销售效率判断。
openai.com
Mural 语音陪练每半小时成本 3—5 美元，AI 原生应用仍受用量经济性约束
William Imoh 在访谈中称，连续使用 Duolingo 一千天后仍难以用挪威语交流，因此用 Codex 和 GPT-Live 开发沉浸式语言陪练 Mural。没有 Swift 或 Kotlin 经验的他完成了原生 iOS、Android 应用，并把产品需求写成明确的用户故事。按其披露，30 分钟实时语音会话约消耗 3—5 美元，体验已可用，但推理成本仍高。他还用连接企业工具的角色化 Grok Bots 协助运营约 25 人的公司，并自建招聘数据系统；文中没有披露 Mural 的收入或留存。
🦐点评：Mural 的 3—5 美元会话成本会直接约束低价无限量订阅。语音教育产品的估值应建立在付费课时、续费和每分钟贡献利润上；若只用下载量证明产品成立，很容易把活跃用户增长变成亏损增长。Imoh 还展示了从未写过 Swift 的创始人开发原生应用的路径，前端开发本身更难支撑溢价。
www.lennysnewsletter.com

AI 硬件周期访谈：供给扩张与融资成本，比远期需求故事更值得拆解
刘迪凡在晚点访谈中判断，AI 硬件三年牛市可能结束，但不能直接等同于 AI 泡沫破灭；依据包括供给扩张、基金持仓分散与算力回报压力。他举例称磷化铟供应商从3家增加至7—8家，并提出 GPU 租价、信用利差、积压订单和应收账款四项观察指标。文中“2万亿美元基建需要每年3.7万亿美元 AI 收入”是建立在折旧、12%税前回报、50%云利润率和30%收入分成等假设上的测算。受访者对2027年供需、Neocloud 风险及模型公司估值的判断均属观点，不能当作已经发生的结论。
🦐点评：访谈把 Neocloud 的融资成本放在核心位置，这对私募投资同样适用：一家公司的订单可以增长，下一轮融资仍可能因信用收缩而中断。看算力、存储和上游器件标的，应要求把不可撤销订单、客户预付款、债务到期与设备残值放进同一张现金流表；只验证需求增速会漏掉融资先于需求断裂的风险。

Meta 买 Conductor、OpenAI 买 Pierre：Agent 编排与代码审查成为并购补位方向
深思SenseAI 梳理称，Meta 收购约6人的 Conductor，OpenAI 同日宣布收购十余人的 Pierre Computer，文中未披露交易价格。Conductor 在独立 git worktree 中管理多个编程 Agent，并通过 PR 审查合并；报道称其用户超过10万，今年3月刚完成2200万美元 A 轮。Conductor 云端拟于11月13日转只读、20日关闭，本地版可继续用至2027年初。Pierre 的代码存储与审查能力则计划整合进 Codex，开源项目继续开放；融资、用户及安排均据该文转述。
🦐点评：Conductor 融资七个月后卖身，却没有公开价格，不能把“被大厂买走”直接算作 VC 的成功退出。两种产品处置路径更值得追问：客户最终愿意为独立编排层长期付费，还是这层能力更适合成为模型平台的功能？下一批标的应证明企业级权限、审查记录或跨团队交付能形成续费理由。

Fable 5.2 视觉与前端实测：长任务质量提升，额度消耗仍限制日常使用
卡兹克展示用 Fable 5.2 一次提示生成动效视频、Three.js 场景与苹果静安店3D网页的个人测试。静安店案例中，模型查阅真实照片与报道，再完成建模，作者称全程约两个半小时。约四小时、十项主要使用 Xhigh 的任务后，其订阅已用额度从70%升至94%；这个数字不能换算为统一的 API 单价。作者因此更倾向把 Fable 用于规划与指挥，再按任务交给其他模型；展示的是个人案例，未提供重复试验成功率。
🦐点评：静安店案例用了两个半小时检索和建模，说明创作产品可以把等待时间转化为质量，但需要客户接受异步交付。投视频、设计或3D Agent，应验证用户肯为哪类成品等待、失败后重跑几次以及整单毛利；如果卖点只有一次惊艳的直出，底层模型更新后很难保住价格。
