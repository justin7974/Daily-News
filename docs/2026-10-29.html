🔥 精选推荐

AA v5 拉大开闭源差距，Nathan Lambert 提醒别把总榜当市场
Artificial Analysis v5 将知识工作、编程、科学和通用能力各赋予 25% 权重，榜上有八个闭源模型超过最强的待开放权重模型 Kimi K3.1 Pro。Nathan Lambert 认为，这部分反映了评测向前沿科学和通用 Agent 协作倾斜，不能据此判定开源模型的商业价值衰退。他把开放模型的机会归于降低高需求任务的推理价格，以及让企业拥有、定制并控制模型。他支持减少针对公开题目的过度优化，但担心私有题库削弱外部纠错；同时指出评测机构向模型公司收取验证费用带来的信任取舍。
🦐点评：Kimi 在科学任务上的差距，未必会让企业为成熟编程任务多付钱。看开放模型公司，应把榜单分数与客户任务毛利分开核算；如果低成本推理仍有不错利润，真正要追问的是成本优势能保持多久、谁能保住客户，而非总榜还差几名。
interconnects.ai
Supabase 每月新建约五百万数据库，Agent 开始影响后端转化率
Supabase 两位创始人称，平台目前每月新建约五百万个数据库，AI 驱动的使用增长还改善了激活和付费转化。他们认为，Agent 能把注册、配置到应用可运行连成一次流程，减少用户在配置阶段放弃。新发布包括无需 Docker 的本地运行环境、把目标数据库结构保存在 Git 中的声明式 schema，以及在数据库旁运行容器的 Compute，部分功能仍处于 alpha。产品同时推进 OrioleDB、Multigres 和 Turso 收购后的扩展能力，以兼顾大量小数据库与既有客户的大型负载；增长数据来自创始人口径。
🦐点评：Supabase 的案例提示，开发工具的分发对象已经包括替用户选技术的 Agent。但五百万新库也可能包含大量短命原型，不能直接当作付费客户增长；这笔生意要看这些应用三个月后还剩多少、留下的应用是否持续增加计算和存储支出。
latent.space
a16z 调查：AI 安全预算在增长，采购仍先找既有平台
a16z 调查了 100 位千人以上企业的 CISO，其中 87% 预计 2027 年安全支出增加，但只有 18% 已在生产环境使用 AI SOC 工具。未来十二个月，45% 计划采购或升级内部 Agent 安全产品，42% 指向进攻性安全。采购入口仍偏向老供应商：44% 会先找既有安全平台，21% 先找 AI 原生厂商；47% 表示，现有平台无法解决的能力缺口会促使他们选择创业公司。调查也显示，仅 7% 预计一年后会允许 Agent 在多数情况下自主行动。文章来自投资方，并推荐多家被投公司，预算意向和推广判断都不等于已确认收入。
🦐点评：44% 先找老平台，意味着“安全预算增长”不能平均分给一批 AI 创业公司。更值得约的是能拿到具体新增权限、完成修复并验证结果的团队；若只能多报一批告警，客户很可能等 CrowdStrike 等既有供应商补功能，再把价格压回去。
a16z.news
NVIDIA 开放可提示的多语转写模型，把定制工具一并交给开发者
NVIDIA Nemotron 3.5 Transcribe 将录音转写、说话人标注、翻译和音频问答放进同一开放权重模型，支持 40 种语言转写、31 种语言与英语互译，以及最长一小时、最多八位说话人的录音。模型约 30B 总参数、每 token 约 4B 激活参数，发布文称其位居多项开放模型语音榜单前列。配套 Granary v2 公共清单覆盖约 46.3 万小时、48 种语言，并开放清洗流程与微调配方。在发布方医疗案例中，对未参与调参的说话人，微调将词错误率从最佳提示词基线的 22.44% 降至 12.17%，相对下降 45.8%。该模型针对已录制音频，并非实时流式语音；量化和部分本地运行支持尚待发布。
🦐点评：NVIDIA 连数据加工和微调方法一起提供，会压缩通用转写 API 靠封装收溢价的空间。医疗案例仍需领域语料，说明专有录音、准确的人名药名标注和客户工作流程更可能留住利润；投语音公司，应核对这些资产归谁，以及客户换底层模型是否仍离不开产品。
huggingface.co
Simon Willison 实测：Agent 已能改进游戏玩法，人工工时并非全部成本
Simon Willison 用 Opus 5.5 制作了四款浏览器游戏，认为进步已从生成画面和代码延伸到设计更有趣的玩法。他的 Battle Drones 已支持多人对战、回放、地图生成和模型互相对战，并在开放源码后出现重新设计美术与音乐的分支作品。每个项目投入的人类工作不超过四小时，但南瓜农场游戏另用了数百万 token 和近两天 Agent 执行，作者仍不满意部分机制。RPG 项目也经过反复试玩，修复角色位置与任务冲突后才完成；这些是个人实测，并非系统评测或商业成功证明。
🦐点评：Battle Drones 开源后很快被改成另一套题材，预示游戏原型和美术变体会更便宜，也更容易复制。创作工具若只卖“帮你做出第一版”，收费会越来越难；更有价值的是帮助团队反复测试玩法、找到用户并提高留存，且能把两天 Agent 的成本压到合理水平。
simonwillison.net
