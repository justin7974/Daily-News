Salesforce 拟向外部 Agent 收费，企业软件开始争夺机器调用收入
The Information 报道，Salesforce 计划最早于下月要求企业注册外部 AI Agent，把 Agent 更新或分析数据的动作纳入可计费交互，为收费做准备。此举覆盖使用 Claude 等外部工具工作的客户，让未购买 Salesforce 自家 AI 产品的调用也可能产生收入。补抓的公开节选称，目前尚未开始收取这类费用，价格也未公布；新客户在价格公布后有三个月注册宽限，现有客户则到续约时才受新定价影响。注册同时用于赋予 Agent 独立身份和更窄的数据权限。
🦐点评：企业 Agent 的毛利可能被底层应用的访问费重新分配。看销售、客服和运营 Agent，应该把“模型费之外，每完成一单要向业务系统付多少钱”算进去。Salesforce 的客户数据和流程控制权，比它能否做出最强模型更直接地影响定价。
www.theinformation.com
Modal 自报年化收入突破 10 亿美元，沙箱已贡献约三分之一收入
Modal CEO Erik Bernhardsson 在 Latent Space 访谈中介绍，客户按需使用 GPU，而供给通常按固定数量、固定期限采购；Modal 汇集不同客户的需求，以弹性调度减少闲置。文中称公司完成 7.5 亿美元 D 轮、估值 160 亿美元，年化收入突破 10 亿美元，累计创建近 30 亿个沙箱；这些为公司披露，年化口径不等于已确认全年收入。编码、后台 Agent 和强化学习推动沙箱业务增长至约三分之一收入。CEO 也承认，若 GPU 市场价格下降，提前锁定的高价容量可能成为负担。
🦐点评：沙箱收入占比说明 Agent 的执行环境已经能成为独立的大业务。但弹性销售配上长期采购，会让收入增长与库存风险同时增加。尽调应看客户需求能否相互错开、采购合同有多长，以及扣除闲置和启动成本后的毛利，不能直接按收入倍数套普通 SaaS。
www.latent.space
ThinkingBox：用数据库最终状态训练 Agent，重复成功比偶尔成功更难
微软与 Hugging Face 把“数据库最终是否被正确修改”变成强化学习奖励，在独立于测试集的任务上训练 Qwen3.8-27B。经过 50 步 GRPO，507 项测试的平均成功率从 51.70% 升至 60.78%；每项重复 20 次且全部通过的任务，从 38 项增至 107 项。不过至少成功一次的任务反而从 453 项降至 446 项。作者同时估算单次成功尝试成本由 0.177 美元降至 0.139 美元。上述结果来自特定评测，20 次全通过并不保证生产环境永不出错。
🦐点评：企业客户通常不愿为同一笔退款或预订试错二十次。这类训练的价值，是把可检查的业务结果变成稳定反馈。能拿到真实任务、权限约束和最终账目数据的团队，有机会用较小模型降低成本；但平均成功率约六成，也说明关键写操作仍需确认与兜底。
huggingface.co
PHP2Shell：AI 找洞之外，更难的是两个月的联合修复
Latent Space 汇总 PHP2Shell 的多方披露：Calif/OpenAI 与 Wiz 分别报告了 PHP 内核的严重内存问题，涉及内存耗尽及致命错误处理；研究者展示了对部分主流 CMS 的远程执行或内存泄露攻击。参与方称，修复涉及 PHP 引擎修改、补丁验证，以及维护者、云厂商和安全机构约两个月的协作。Cloudflare 在正式补丁前部署临时 WAF 规则，并强调仍需更新 PHP。文章也区分了研究者的利用演示、观察到的攻击流量与已确认入侵，不能把所有相关网站停机归因于成功攻击。
🦐点评：安全产品的瓶颈开始从发现漏洞移向安排修复、测试回归和验证线上版本。更值得看能缩短实际暴露时间的产品，而非只增加告警的扫描器。此次是多方共同发现和修补，也不宜把厂商宣传中的模型能力排名直接用于采购或估值。
www.latent.space

Hone 融资 6000 万美元，让常驻 Agent 对业务结果负责
文章援引 Index 与创始人材料称，Hone 成立五个月，完成 6000 万美元种子轮，Benchmark、Index 领投，估值 2.85 亿美元。产品 Engine 接受提高留存、降低采购成本等目标，学习企业系统和约束，再持续执行并从结果中改进；敏感操作需批准，动作留有记录。团队成员来自 Cognition、Harvey、Mercor 等公司，早期使用者包括 AI 企业。文章主要依据公司与投资人论述，未披露规模收入、长期留存或业务改善的对照结果；报道所述融资于 10 月初宣布，并非当天新交易。
🦐点评：Hone 把目标持续管理、企业记忆和权限放在一起，方向比一次性聊天更接近客户愿意付费的工作。但按损益表评价产品，首先要解决归因：留存改善有多少来自 Agent，有多少来自市场变化。投资前应要一段完整运行记录，统计人的接管次数、错误动作和新增毛利，融资额不能替代这些证据。

AI 招聘转向具体岗位与工业经验，顶尖薪酬和普遍扩招开始分离
晚点采访学生、研究员、猎头和招聘负责人，发现基础模型团队配齐后，招聘更关注候选人补足哪类能力，校招名额、面试入口与转正机会都在收紧。大规模训练、强化学习、推理和基础设施经验仍有溢价，论文和头部公司实习经历却不再保证录用。报道还指出，后训练、Agent 和数据基础设施仍有需求；新人能否接触算力、核心项目与成果部署，比简历上的团队名字更能决定后续成长。这是多方采访呈现的结构变化，并非全市场招聘数量统计。
🦐点评：不能把少数研究员的天价 offer 当作整支团队都缺人的证据。看模型创业团队，应核对关键成员在训练中真正负责过什么、是否拿到过可复现的收益；同时看新人有没有独立实验和部署机会，否则名校与大厂履历堆得再高，也不一定提高研究效率。
