Mistral Large 4 开放权重，网络安全成为差异化切口
Mistral Large 4 是约一万亿总参数、百万 token 上下文的多模态 MoE 模型，开放 FP8、NVFP4 权重，并同步支持多种推理与微调框架。发布文列出的漏洞复现并修补测试得分为 82%，同时提醒部分闭源模型因拒绝执行相关任务而得分很低，不能简单视为通用能力差距。模型许可对模型即服务业务设有限制，开放权重不等于无条件商业使用。部署示例中，512GB 统一内存的 Apple Silicon Ultra 可运行两比特量化版本，但长上下文仍会明显拖慢速度。
🦐点评：网络安全客户买的不只是答题分数，还包括事故期间不会突然失去模型访问权。Mistral 给安全团队更多部署和策略控制，垂直安全公司的差异化就要向专有漏洞数据、修复验证和客户权限体系迁移；想靠托管同款模型收费的团队，还需先核清许可与实际服务成本。

ChatGPT 订阅附带等额 API 额度，模型预算开始跨入口流动
Simon Willison 记录，OpenAI 已为符合条件的 100、200、500 美元订阅提供同额 API 额度，可用于用户的一个 API organization。此前 Anthropic 已为相应订阅提供类似权益，额度会过期。作者认为，既有订阅覆盖了实验所需的部分 API 成本，使他更愿意发布面向公众的演示。这是订阅权益扩展，不代表 API 调用变为无限量，也不能按现金返还理解。
🦐点评：两家把 API 额度塞进订阅，会改变独立 Agent 工具的获客账：能承接用户现有额度的产品，可能比另收一笔模型费更容易启动。看这类公司的留存，要等赠送额度耗尽后再看一次；补贴期间的调用增长，不能直接外推长期毛利和付费意愿。

Spawn 自述每月花逾三百万美元 token，尝试由 Agent 持续开发游戏
Spawn 创始人 Jacob Sansbury 自述，产品由 Fable 驱动的 Agent 群持续开发，每月 token 开支超过三百万美元，约为工资开支的三十倍。游戏内 Agent Savi 能根据玩家提示修改世界，并把遭遇的问题提交给开发 Agent；约六成开发工作由线上错误、日志或用户反馈触发。团队声称每小时发布，出现问题可在三十秒内局部回滚。Simon 亲自体验了生成城堡和骑龙，但提醒这种自治方式在高风险软件上未必适用；运营与成本数字仍是创始人口径。
🦐点评：工资的三十倍花在 token 上，意味着“小团队”已经不能作为资本效率的替代指标。投 Spawn 这样的产品，要把模型支出、回滚运维和用户贡献毛利放进同一张表；如果世界生成越受欢迎就亏得越快，开发自动化反而会加速现金消耗。
simonwillison.net
Elorian 用诱饵计数暴露视觉推理短板，自报成绩仍刚过五成
Elorian 与 Mercor 发布 DecoyCount，测试模型会不会把镜像、包装标识等视觉线索误当成实际物体数量；论文中最佳前沿模型准确率为 43.17%。CEO Andrew Dai 称，自家 Glimpse 在 1660 道题上达到 50.48%，评测图文未进入其训练数据，但这是内部单次结果，其他模型则取三次平均。Glimpse 的方法是把生成和编辑图像纳入推理过程，而非只输出图像或模拟可导航世界。公司今年四月披露五千五百万美元种子融资，并将机器人、工程与防务列为潜在应用。
🦐点评：Dai 的背景和五千五百万美元种子轮能支撑技术投入，却还不能证明产品可用。若切入仓库盘点或建筑合规，接近一半答错的计数表现意味着仍需大量人工复核；下一步该看同一客户任务上能减少多少复核工时，以及错误是否集中在可识别、可拒答的场景。
latent.space
Agent 提速的瓶颈常在工具与沙箱，不能只比较 token 吞吐
Martin Alderson 根据过去一年的工程实践，把 Agent 延迟拆为首 token 时间、生成速度、工具调用以及环境挂起与恢复。短回合任务更受首 token 时间影响，长代码输出则更依赖吞吐；调整推理预算有时比购买更快的服务档位更有效。他建议查看工具轨迹，优先处理重复启动进程、输出过量、轮询等待和不合适的数据接口。文中的示意分解显示，即使推理耗时减半，若其他环节不变，总任务时间也可能只下降约两成；这不是跨产品实测结论。
🦐点评：如果推理减半只换来两成端到端改善，单卖“更快模型”的溢价就有天花板。看 Agent 基础设施，应要求团队拿真实客户任务证明完成率、耗时与总成本同时改善；能消掉工具往返和环境恢复开销的产品，可能比单纯转售推理更容易保住价格。
martinalderson.com
