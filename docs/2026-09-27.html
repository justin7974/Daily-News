How New Mexico’s Oil Windfall Became a $2 Billion VC Bet
新墨西哥州 750 亿美元的主权财富基金，在新油气收入膨胀后改变了对创业投资的策略，过去三年向 VC 基金投入约 20 亿美元，这笔"石油美元"正流入硅谷，同时让该州在 AI 热潮中分一杯羹。报道以人工增雨创业公司 Rainmaker 为例：26 岁的创始人 Augustus Doricko 在阿尔伯克基郊外操控无人机，准备在格兰德河一带用碘化银人工催雨；Rainmaker 的多个投资方正是拿了该基金钱的 VC。（正文付费，以上基于公开部分。）
🦐点评：一个只有 750 亿盘子的州主权基金，敢在三年里往 VC 砸 20 亿，说明油气边际收益正在被系统性转化为"本地科技主权"——这类"小而急"的地方 LP 很可能比中东土豪更好谈条款，是 GP 募资的新增量。但要警惕它们的回流诉求：钱越多，"必须投本州/带动本地产业"的附加条件会越硬，Rainmaker 这种在本地落地试验的项目就是样板。

Why Wall Street’s Big, Bad Bears Aren’t Ready to Bet Against AI Yet
靠做空 2008 年次贷成名的 Steve Eisman 已是 AI 泡沫论的代表性批评者，但他明确说"我还没准备好下大空单"。他紧盯英伟达向 Anthropic、OpenAI 供芯片的关系，直言"整条链依赖两家大亏钱的公司"；并把 OpenAI 迟迟不上市视为可能的做空催化剂——他判断对这类"持续失血、必须不断融资"的公司，叙事极其重要，一旦 OpenAI 继续推迟 IPO，就可能是他出手的信号。（正文付费，以上基于公开部分。）
🦐点评：最有信息量的是空头的"等待条件"——不是估值，而是 OpenAI 的上市时点。当做空扳机挂在"循环融资何时断"上，说明市场已把 AI 叙事与持续融资能力绑定。对 GP/LP 而言，OpenAI IPO 不只是退出事件，而是整条 AI 资本链的压力测试点：它一旦成功，所有"靠叙事续命"的公司估值都会被重新锚定；一旦拖延，Eisman 这类空头才会真正进场。

BREAKING: AI agent incident toll has risen to tens of thousands
Gary Marcus 引用 Axios 记者 Madison Mills 的独家报道称，AI Agent 相关安全事件的数量已达"至少数万起"——此前外界只知 Hugging Face、一家德国网站，以及 OpenAI 承认的"数十起"。他批评美国政府毫无调查、声明或产品召回动作，还援引 Cursor 插件盗走加密钱包等案例，强调这些风险"完全可预见"，并称他自 2023 年起就多次向参议院和公开文章警告 Agent 安全。
🦐点评：Marcus 的价值不在情绪，而在他给出的产业判断——Agent 因消耗 Token 远超聊天机器人而被厂商纵容狂奔，安全被牺牲换营收。如果"数万起事件"被监管采信，Agent 赛道最大的非技术风险（合规与责任归属）会从边缘变量升格为估值折价项。投 Agent 基础设施时，可观测性、权限隔离与身份核验层，可能比模型本身更值得下注。

Microsoft Took the ‘Copilot+ PC’ Brand Out Behind the Shed
微软与 PC 厂商已悄然弃用 2024 年力推的"Copilot+ PC"品牌：2026 年发布的 Surface 新品不再冠名，高通也把重点从品牌名转回"NPU 体验"，英伟达更刻意不让 RTX Spark 使用该标识。报道称，Recall 安全风波与 Copilot 本身口碑不佳共同拖累了这一品牌，但 45 TOPS NPU 的规格基线仍然保留，只是不再有一个漂亮的营销名。

美国保险公司说，医院的 AI 让它们两年多付了9.42亿美元
美国蓝十字蓝盾协会（BCBS）9 月 24 日发布三页白皮书称，2023—2025 年医院用 AI 辅助编码把越来越多的住院病例编成复杂病例，导致蓝十字体系两年多付约 9.42 亿美元。文中举例：在诊断增长最快的医院，产妇"急性失血后贫血"病历占比从 2022 年二季度的 4.0% 升到 2025 年一季度的 12.3%，但同期输血比例仅从 0.8% 升到 1.2%，"模式指向 AI 辅助编码"。文章详述 DRG 分档机制——同一台肠道大手术按次要诊断可分为三档，付费差一倍以上；白皮书称两年里多出 55158 个复杂病例，每例平均多付约 1.18 万美元。美国医院协会否认指控，反指保险公司也在用自动化砍账单。
🦐点评：这是 AI 落地医疗后第一批"可量化副作用"的样本——AI 编码不是在提升医疗质量，而是在提升账单，规模大到能被保险公司写成白皮书。对投资判断有两点：其一，医疗 AI 的 ROI 在支付方与供给方之间高度对立，卖给医院的产品可能被保险公司视为对抗工具；其二，"AI 合规审计"本身会成为新赛道，谁能为 DRG/AI 编码提供可解释、可追溯的证据链，谁就握住了支付方的刚需。医院否认叠加保险公司也在自动化砍账，说明这是一场双向的信息不对称竞赛，很难靠单一产品解决。

深度｜对话OpenAI Codex负责人Tibo：从内部工具杀到顶流，Codex的终极目标不只是Coding Agent
这是 The Pragmatic Engineer 对 OpenAI 核心产品与平台负责人、Codex 创建工程师之一 Tibo Sottiaux 的访谈译文。Codex 最初只是 OpenAI 内部帮研究员写 Python、搭基建的小型智能体，后与"自主软件工程师"（ASWE）项目合并，成为今天的 Codex。文中复盘了关键工程决策：为什么用 Rust 重写核心智能体、为什么从第一天就开源 CLI 和 SDK、为什么 Codex 不绑定 OpenAI 自家模型，以及如何把本地 Coding Agent 推向云端并与 ChatGPT 统一。他还谈到代码审查的职能变化——正确性与安全审查将更多自动化，人类应把注意力放在产品意图与架构边界上。 <!-- ai-daily:complete -->
🦐点评：最值得投资人记住的是 Codex 的"不绑定自家模型"和"开源 CLI/SDK"——这是 OpenAI 在 coding agent 战场上主动放弃锁定、换取生态占位的信号，说明它判断这个赛道的胜负手是分发和习惯，而非模型独家。对做 coding agent 的创业公司是双刃剑：底层能力被免费化，护城河只能建在工作流、企业权限和评测数据上。Tibo 把"人还剩什么"定义为产品意图与架构边界，等于给这一层划了价——越靠近"定义要解决什么"越难被替代，越靠近"写与查"越先被吃掉。
