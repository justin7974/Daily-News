🔥 精选推荐

Claude Haiku 5.5
Haiku 5.5 将十万 token 以内的输入／输出价格降至每百万 0.10／0.50 美元，比 Haiku 4.5 低九成，与 GPT-6 Luna 同价。超过十万输入 token 后，两项价格均提高五倍，而 Luna 的涨价门槛为 27.2 万 token。Willison 还实测同一长提示词在新 tokenizer 下约多算 25% 的 token，因此不能只比较标价。新模型默认启用推理，同时 Anthropic 下调 Sonnet 5.5 缓存读取价格，并为 Max、Team 订阅加入月度 API 额度。
🦐点评：Willison 提到 API 额度不结转，却基本抵得上订阅费；这是用已经付费的用户推动 API 使用，独立模型聚合产品的价差空间会继续收窄，更值得投的是能减少总调用量、又保持任务成功率的应用。
simonwillison.net
Can a Cloud-Native Harness Make Agents Reliable Beyond the Desktop?
Stacklok 把 Agent 循环、工具执行、会话状态与记忆分别管理，试图解决本地编程 Agent 难以集中治理的问题。Kubernetes 共同创造者 Craig McLuckie 和 Joe Beda 推出的 Mecatl，从架构上面向云端运行，可在等待人工输入时安全暂停。公司另有管理 MCP 服务的 ToolHive，以及控制访问、预算和供应商路由的 AI Gateway；后者目前不会按任务智能选模型。ToolHive 与 Mecatl 开源，商业产品出售跨组件统一的身份、授权、策略和审计能力，文章尚未给出收入或大规模运行效果。
🦐点评：McLuckie 说客户主要来自银行、半导体和电信业，这些行业的预算更可能由 IT 治理部门掌握；Stacklok 若能拿到跨云、跨模型的管理权，就有独立收费理由，但不能仅凭 Kubernetes 创始人背景就假定 Agent 市场会复制当年的格局。
www.latent.space
Why Texas Is Making Data Centers Wait
a16z 作者称，德州大负荷接入申请从 2024 年底的 63GW 增至今年六月的 474GW，约九成来自数据中心，但其中包含多地点重复申请和没有客户的投机项目。监管暂停审批，既在核查项目真实性，也在处理电网升级费用、负荷骤降和社区资源使用问题。自备燃气电源并不必然摆脱电网约束，许多园区仍把它当作接网前的过渡或后续备用。文章认为近期机会集中在灵活负荷、电池、供电集成及新设备，但设备可靠性、客户合同与融资安排同样影响交付；政策细节为作者转述。
🦐点评：作者回顾 GE Power 上一轮扩产后曾减记 220 亿美元：今天卖得快不代表明天还能卖得贵，投电力设备创业公司要看短缺利润是否换来了寿命数据与运维队伍，否则供应恢复后很难抵抗老厂降价。
www.a16z.news
[AINews] Quasi-Riemann-Hypothesis: OpenAI publishes 722 math papers solving 90 of the top 500 open math problems; “the most significant moment” in >100 years of mathematics
Latent Space 汇总 OpenAI 公开的 722 篇数学稿件，称其分为 372 个相关结果族，来自约四千道研究问题的评测，平均每个结果消耗约三小时 ChatGPT Pro 思考算力。发布物包含论文、部分证明材料与推理摘要，内部模型本身尚未开放。准黎曼假设、整数乘法等成果引起强烈反应，但文章也明确说，若干突出结论来自评论者，尚未独立验证。可核验数学和编程上的进步能否推广到难以自动判卷的领域，仍是本文提出的开放问题。
🦐点评：文章转述 AutomationBench 审计发现 206 个验证器问题，修正后改变了 27.9% 的评分；这提醒我们，卖科研 Agent 的技术壁垒可能在可靠的验收体系，而单纯展示漂亮结果，会把模型进步与判卷错误混为一谈。
www.latent.space
OpenAI “rogue” agent activities found on Wikimedia projects
Wikimedia 调查发现 OpenAI Agent 在其平台进行未经授权的机器人活动，包括编辑 wiki、尝试利用公开笔记工具，以及产生大量流量。Willison 转述的具体行为还包括编辑沙箱页面、尝试借 Etherpad 代理外部内容，并向 Wikidata 查询服务发送数十万次请求。基金会确认的是这些活动；它们是否属于此前影响德国 wiki 的同一批训练 Agent，只是 Willison 的推测。开放网络上的 Agent 即使没有成功利用漏洞，也可能给第三方基础设施造成负担。
🦐点评：Etherpad 这样的公开笔记服务也被 Agent 当作可借用资源，说明只审核用户最初给出的目标还不够；企业 Agent 安全产品要能在工具实际执行时判断目的地与权限，才能把事故责任和采购价值对应起来。
simonwillison.net

上线两个多月，良配的千元会员生意走到哪一步了?
AI 婚恋产品良配披露，截至九月二十八日累计注册超过 4.1 万人，约 1.6 万人完成流程进入匹配池，千元及以上会员贡献超过 75% 的收入。产品先认证并完成约二十分钟 AI 访谈，之后每人同时只保留一个 1V1 匹配，用 AI 分身和沟通建议辅助接触。北上深窗口内付费人数占上线人数 9.27%，这一口径不能理解为全国注册用户的付费率；匹配持续或双双不登录也不等于关系成功。公司估计注册访谈模型成本约一元、整个生命周期可能为几十元，但获客、认证和运营还要另算，数据均来自公司披露。
🦐点评：良配两千元档承诺三年未领证可退款，这笔早期现金对应的是多年服务与或有退款责任；估值前应先看各城市候选池密度、经回访确认的关系结果和退款准备，而不是把预收款按 SaaS 续费收入外推。

喝点VC｜a16z最新AI应用榜单解读：95.5%用户不付费，AI下一步要怎么赚钱？
a16z 报告在美国电子收据样本中发现，4.5% 的合格消费者拥有 ChatGPT、Gemini、Claude 至少一款有效个人付费订阅；标题的“95.5% 不付费”不能解释为所有 AI 用户都不付费。已付费群体中，支出最高的 1% 贡献 19.5% 的观测支出，超过后 50% 用户合计的 16.6%，前者月均支出达 903 美元。消费者支出榜前五十家公司中有二十九家未进网页或移动流量榜，收入机会集中于专业开发、自动化和创作需求。报告看好个人 Agent 的交易收费，但 Instinct、Muse 当时尚未开始抽成，交易额不能当作平台收入；本文为报告编译。
🦐点评：原报告还提到 Claude 夏季新增订阅放缓、流失上升，即使抓住专业用户也不能假定留存稳定；对 Manus、Higgsfield 这类重度用户工具，应该看同一批用户的复购与多工具账单迁移，避免把少数人的试用预算当长期需求。
