Linux 安全研究走向批量验证：948 个本地提权漏洞，API 开销约 121 万美元
OpenAI 披露，10 月中旬的一轮研究以尚未发布的 Cyber 模型扫描 Linux 内核：2,308 个候选发现中，动态复现 1,724 个漏洞，完成变体分析后按 948 份不同补丁计数本地提权漏洞。整轮 API 开销为 1,213,430 美元，平均每个约 1,279 美元，尚不含全部人工与基础设施费用。流程覆盖发现、复现、利用验证和候选补丁，最后仍由人审查并向维护者报告。这是厂商自报的受控研究，涉及已有低权限账户的本地提权，不能理解成远程直接攻破 948 个系统，也不表示补丁均已合入。
🦐点评：找漏洞的供给增加后，安全公司的收费依据会更多落在判重、优先级、可合入补丁与客户实际修复上。研究还发现早期 200 个“成功提权”中有 20 个走了错误漏洞，说明只验最终结果会高估 Agent 能力。尽调应检查每个修复能否对应原始漏洞，以及维护者真正接受了多少。
openai.com
OpenAI 拟收购 Pierre，把 Git 存储、代码浏览与审查接入 Codex
OpenAI 宣布将收购 Pierre Computer Company，后者提供 Code Storage，以及 Trees、Diffs、Highlights 等开发工具。Trees 与 Diffs 已用于 Codex 应用的文件浏览和变更审查；Code Storage 支持应用通过 Git 存代码与历史。公告把收购与内部 Git 后端 Pando 的并行开发需求联系起来，计划将相关能力带入 Codex。交易金额未披露，仍待常规交割条件和监管批准，双方在交割前保持独立；开源项目将继续开源，Code Storage 客户在交割后仍可使用服务。
🦐点评：模型厂商正在把代码生成前后的操作也纳入产品。独立开发工具若只改善浏览或 diff 展示，会面临平台整合压力；更值得看的是跨模型协作、企业权限和审查责任。收购能说明 OpenAI 重视这些环节，尚不能证明它已拿到客户完整的软件交付流程。

小银行为 Agent 开设受限账户：支付基础设施开始出现交易量
据 The Information 页面公开内容，Lead Bank 允许合作方为 Agent 配置专用账户号码，并设置交易、支出限制及即时停用控制；Increase Bank 计划提供与客户其他资金隔离的账户，通过 API 验证 Agent 授权。报道还介绍 Natural 与 Column Bank 的钱包安排，以及酒店运营 Agent Conduit 的收付款用途。Cross River Bank 自报，近三个月其支持的 Agent 卡支付超过 4,000 万美元、20 万笔交易，航空是主要消费者支出类别。上述是报道与银行口径，本期未独立核验；误付后的赔付责任仍未解决。
🦐点评：比“Agent 会购物”更有价值的信号，是银行开始提供单独账户、限额和撤销权限。支付创业公司的机会可能落在授权、对账和争议处理；但 4,000 万美元是单家银行披露的支付额，既不是平台收入，也不能外推市场规模。应追问真实活跃账户、重复支付率和误付损失。

Stratechery：数据中心的下一道约束可能是地方许可与选民反对
Ben Thompson 结合美国中期选举报道与地方投票，提出 AI 算力扩张的瓶颈可能从芯片、内存和电力进一步转向政治许可。其推演是：已有获批站点的价值上升，新建项目较多的 Neocloud 承压，能改造既有设施的 Hyperscaler 更有优势；固定电力下的 token 产出效率、端侧推理与小模型也更重要。文章同时承认，限制能否长期持续尚不确定。这是一篇情景分析，文中选举报道、政策承诺与尚未落地的监管不能混作既成法律。
🦐点评：算力投资要把土地、电网接入和建设许可分别查清。“拿到融资”与“按时交付算力”之间还有很长距离。若许可趋紧，存量资产可能受益，但依赖新站点偿债的公司风险会更高；这个判断需要逐项目验证，不能据一轮选举就假定算力永久短缺。
stratechery.com
Dharma 用 2B 模型做文档字段提取，成本优势取决于部署口径
Dharma-AI 发布面向文档图像的字段提取模型，支持自行识别字段或按指定 schema 输出 JSON，缺失值返回 null。团队以 43,384 个样本训练 LoRA，在 546 份文档、1,638 个测试案例中报告综合得分 0.834，高于所测 Claude Opus 5 的 0.816。团队称成本比所测 API 低约 6—147 倍，但一边按单张 L40S 的 GPU 时间、每小时 2.24 美元计价，另一边按 API 标价；通用模型主要采用低推理配置。结果是发布团队自测，不代表所有文档、最新模型或实际服务报价。
🦐点评：字段明确、调用量大的任务，专用小模型仍可能有很好的单位经济性。关键是把低负载时的闲置、部署维护、异常件人工复核一起算入成本。对票据和合同类产品，应拿客户真实脏数据测漏项、错行与空值，不能只比较平均分。

无涯智远探索参数内学习：超网络写入知识，长期稳定性仍待突破
Z Potentials 访谈北大张牧涵，介绍无涯智远的 In-Parameter Learning：训练超网络，通过一次前向传播生成基座参数更新，避免每次写入都做在线反向传播。受访者称超网络规模约为基座的 20%，内部新版在数万 token 测试上可匹配上下文学习，并探索个性化模型 API、Personal Agent 和企业服务。但他也明确承认，更大规模写入尚不能精确召回，从几百次更新走向几千次乃至持续学习仍是研究问题，稳定、遗忘、回滚都是当前重点。属于经受访者确认的公司访谈，内部表现未独立核验。
🦐点评：可投的核心假设是：专属模型吸收企业经验后，能降低上下文开销并提高后续任务表现。应要求同一基座在连续更新后，既记住新知识，也保住旧技能，并能撤销有害写入。导语中的“永不漂移”比访谈正文走得更远，不能据此把已完成的知识写入估值为无限自我改进。
