DeepInfer 的高吞吐依赖高缓存命中，80% 利润率仍是外部测算
据 Latent Space 汇总的 DeepSeek 技术披露，单集群每天服务 155 万亿 token，输入缓存命中率达 96%，因此吞吐量不能理解为新生成 token 数量。报道转述平均首 token 延迟约 400 毫秒、生成速度每秒 230 token，同时指出 KV 缓存管理和负载均衡组件尚未完整开放。vLLM 团队自报，在匹配配置的 GB200 测试中，解码吞吐与 DeepInfer 公布结果相差不到 6%，这不等于复现整个生产服务。标题中的约 80% 利润率及 81 天回本来自外部成本假设与推算，并非 DeepSeek 审计披露，且未完整计入存储、网络、冗余和运营费用。
🦐点评：如果 vLLM 公布的接近结果能复现，单靠推理内核领先获得长期溢价会更难。推理服务商的估值应更多取决于流量是否足够集中、缓存能否重复利用，以及客户迁移后每个成功任务的总成本；把高缓存工作负载的利润外推到所有客户，容易高估盈利能力。
www.latent.space
Tenex：企业买了 AI，非研发 Agent 仍卡在生产部署
Tenex 联合创始人在访谈中称，公司已有 75 人，约一半客户为 Fortune 2000 企业，另一半为年收入 1 亿至 5 亿美元的中型企业。在其接触的约百家企业中，约 90% 已向员工提供通用模型工具，约 50% 配置编码 Agent，非研发工作的生产 Agent 则只有约 5%；这是客户接触样本，并非全市场统计。公司按交付产出激励工程师，并将 AI 策略顾问的激励与客户留存、增长关联，但架构设计和客户沟通仍难用代码产出计价。团队还把客户反复提出的数据权限需求，从定制服务做成了权限网关产品。
🦐点评：Tenex 的权限网关说明，服务公司有机会从重复项目中长出软件收入，但 75 人团队的交付效率不能直接当成 SaaS 的规模效应。看同类项目，应该追问第二个客户需要重写多少权限规则、收入增长是否仍依赖顾问人数，以及产品能否脱离原交付团队独立销售。
www.latent.space
NVIDIA Kumo Relational：把企业预测任务变成数据库查询
NVIDIA 发布预训练关系数据模型 Kumo Relational，直接利用多表关系、外键和时间信息预测流失、需求或欺诈，无需为每个任务重新训练或手工铺平成单表。模型最多取 1 万个历史样本作上下文，通过一次前向计算完成预测；官方在 15 个数据库、41 项任务上报告了优于监督学习基线的总体结果。系统可通过开源库或 NVIDIA NIM 部署，代码与模型权重采用不同许可证。官方也承认，大训练集上的专用监督模型仍可能占优，且有效预测信息需要在有限的关系跳数内可达。
🦐点评：Kumo 把预测接口交给 Agent 后，通用特征工程和逐项建模服务会面临价格压力。更有价值的公司可能掌握业务标签、干预结果和客户愿意执行的决策流程；尽调时应看预测带来了多少额外回款或减少了多少损失，而不只比较离线分数。
huggingface.co
PHP 两项严重漏洞已遭利用，AI 安全需求延伸到补丁交付
KrebsOnSecurity 报道，PHP 两项可导致远程代码执行的漏洞已出现实际利用，影响大量基于 WordPress、Drupal 等系统的网站。报道援引 Censys 扫描，识别出约 258 万个面向互联网的主机和 5490 万个运行 PHP 的网站资产。研究参与方 Wiz 称，前沿 AI 显著降低了把长期潜伏缺陷转成可用攻击的难度；PHP 团队已发布修复，Cloudflare 也部署了防护规则。漏洞披露、补丁验证和大规模更新需要多方协作，发现漏洞并不等于受影响系统已获得修复。
🦐点评：PHP 这类遍布主机商和中小网站的软件，让安全预算有机会从“找出更多问题”转向“替客户完成修复”。能控制托管、部署或更新入口的团队更容易收费；纯扫描工具若持续增加告警，却无法证明关键资产的暴露时间缩短，客户未必愿意扩预算。
krebsonsecurity.com

Othello 融资 800 万美元，把销售辅导搬到通话当下
文章援引融资报道和公司材料称，Othello 完成 800 万美元种子轮，由 a16z speedrun 与 Owl Capital 领投。产品以桌面浮层在通话中提供追问、产品答案和案例，声称无需作为参会者接入，建议延迟低于 500 毫秒。公司称拥有逾 50 家大型企业客户，并在一部分使用超过一季度的客户中观察到赢单率提高 15%、新人上手加快 45%；均为公司自述，文中未展示独立对照实验。文章也指出 Salesloft 已提供实时辅导，且 Salesforce、HubSpot 等厂商可能进入，不能把“通话中提示”视作无人竞争的市场。
🦐点评：Othello 所称的 500 毫秒决定建议来不来得及，但投资回报还取决于销售是否采纳、采纳后是否多赢订单。应要求按客户和销售资历分组，检查真实新增毛利能否覆盖软件费；两千万小时通话数据的授权和训练用途，也比单纯的数据规模更值得核实。
