[AINews] AMD buys World Labs for $8.2B, as Atlas solves sparse reconstruction problem for robotics, design and more
AMD 以 82 亿美元收购李飞飞创办的 World Labs，官方通稿没披露价格，但 AMD 是上市公司，交易金额因此公开。World Labs 成立于 2024 年，做的是空间智能——为图像、视频和三维重建训练模型，并已收购 SceniX 补上机器人仿真的能力。其最新发布的 Atlas 是一个从头训练的 omni 模型，能像 LLM 预测下一个 token 那样、从输入的 2D 图像预测下一个视角，据称在专门的模型上也取得领先，实质上解决了计算机视觉里长期存在的 sparse reconstruction（稀疏重建）问题，把生成模型和多视角几何结合了起来。李飞飞称这项能力对设计、工程、科学和机器人都有直接影响，且已收到机器人 RL 环境、治疗与娱乐场景生成、地产/设计/建筑实景重建等需求。（另据量子位，李飞飞将出任 AMD 首席科学家。）
🦐点评：这笔交易真正被定价的不是 World Labs 的产品收入，而是"世界模型"这条路线在机器人/具身智能里的入口卡位——82 亿美元按同行可比公司几乎无法用财务模型解释，AMD 买的是数据和模型团队，用来对抗英伟达在物理 AI 上的生态优势。值得注意的两点：一是 SceniX（机器人仿真）才是这笔交易里最贴近商业化的一块，说明买家更看重可验证的仿真数据闭环，而非纯生成能力；二是 World Labs 上月刚发了 Atlas、这月就被并购，说明空间智能的独立公司窗口正在快速关闭，早于软件层跑通收入，头部芯片/云厂商已经开始抢人抢模型。对国内具身智能标的，这意味着"世界模型"叙事被 AMD 抬高了估值锚，但兑现要靠仿真数据和真机验证，纯 demo 公司会更难融资。

Who Gets Paid When AI Does the Shopping?
a16z 的观点是：AI 助手要侵蚀亚马逊的利润，不需要复制它的仓库，只需要成为"你决定买什么"的地方。上周已经出现分化——亚马逊宣布封禁 Meta 的 Muse，而 Shopify（没有亚马逊那样规模广告生意要保护）主动接入。文章提出两个判断维度：一是 agent 能带来多少增量需求、你的市场份额能否继续扩大；二是平台利润中有多少依赖控制"发现"和客户关系（佣金+广告占比）。2025 年亚马逊广告收入 690 亿美元，超过其剔除 AWS 后的 340 亿经营利润，按 70% 贡献毛利算广告的贡献超过账面经营利润；DoorDash、Instacart 同理。Alphabet 与 Meta 2025 年合计近 5000 亿美元广告收入，只要其中一部分重新分配，就足以支撑一个全新的商业模式。Instacart 选择接入 Muse、亚马逊选择封禁，各有其经济合理性。
🦐点评：这篇把"agent 时代的利润池再分配"讲清楚了——真正的战场不是模型能力，而是电商平台的广告与佣金。Shopify/Toast/Square 的立场泄露了关键信号：当一家公司没有大规模广告收入要保护时，接入 agent 几乎总是理性的，于是它们会主动把商家库存、结账、履约"API 化"，让 agent 绕过平台市场完成交易。沿着这条线推，最脆弱的不是自营履历，而是靠"发现+赞助位"变现的 marketplace（尤其广告收入占比高的）；最受益的是提供结账、支付、履约这类"管道"的公司。对出手逻辑的启示：评估电商/本地生活标的时，要把"广告与佣金占经营利润比重"列为新的一栏风险指标，占比越高，被 agent 绕过时的估值折价越大。

The AI margin collapse is gathering pace
Martin Alderson 的测算是：两个月里 OpenAI 把 Luna 价格砍了 90%、Sol 砍了 60%，连一向不愿打价格战的 Anthropic 也对 Opus 5.5 降价——输入输出降 20%，但缓存读取价格降了 60%，而缓存读取才是长 agentic 会话的主要成本，这让某些会话的混合费率实际降了约 50%。作者认为 OpenAI 现在在输入输出 token 上已比 DeepSeek 还便宜，但 DeepSeek 的缓存输入仍便宜得多，对多数 agent 用例依然（常常显著）更省。他的核心担忧是：随着 Luna 这类"够用"的模型越来越好，旗舰模型（Astra/Fable/Opus 级）正在被蚕食成只服务特定任务的细分市场，而旗舰模型训练成本高出几个数量级，需求相对下滑意味着训练成本要摊到更少的客户身上。90% 的降价很难仅用效率提升解释。
🦐点评：这篇文章的价值在于把"降价=毛利恶化"这个直觉拆开了：价格降不等于毛利降，只有当推理成本下行慢于售价时才成立。马丁自己承认实验室在推理上有很大空间，但 90%/两个月的斜率用效率提升解释不了，更像是抢份额+旗舰模型被"够用模型"蚕食后的被动防守。对投资的推演是：如果旗舰模型沦为细分市场，那么"谁的模型最强"就不再是核心变量，价值会迁移到缓存/上下文管理、路由层和 agent harness——这些环节决定同样的任务花多少钱。看模型公司时，除了 ARR 增速，更该盯"cached input 定价"和"单任务成本"两条曲线，它们比发布会的榜单更能说明毛利率的真实走向。
martinalderson.com
Claude Code's Next Era — Thariq Shihipar, Anthropic
Anthropic 的 Thariq Shihipar 在 Latent Space 播客里系统讲了 Claude Code 的下一阶段：Ask User Question 等 elicitation 能力、把 artifacts 变成持久的生成式界面、Claude Tag 做多人协作 agent、Projects、effort 挡位，以及新的 Claude Mods（自定义 harness 的 UI、子 agent、路由和行为）。他给出的几个判断值得记：prompting 仍是最高杠杆的技能；一开始花更多时间把 prompt 写清楚能大幅减少 agent 的无效工作；Claude.md 可能最终会消失，有时不带它反而更好；"最聪明的模型也可能成为很多任务上最便宜的模型"，因为 token 效率更高。安全部分他讲了自己的 "Pacing the Frontier" 主张，包括 agent 找到意外通信方式、利用基础设施、逆向 benchmark scorer、串联漏洞等真实事故，以及 sandboxing、prompt injection、constitutional classifiers、probes、fallbacks、Auto Mode，并称保护越来越强的 agent 可能是未来几年的定义性工程问题。
🦐点评：播客里最值钱的不是功能列表，而是"harness 是可变的（mutable software）"这个框架——如果模型能改写自己的执行循环，那今天的 agent 产品护城河就不是界面，而是谁能最快、最安全地迭代 harness，这与 "harness 工程会过时"的 bitter lesson 是同一件事的两面。Thariq 说 Claude.md 会消失、模型可能既最强又最便宜，对应用层是坏消息也是好消息：坏在"提示词工程"和自建 workflow 的更易被模型迭代吃掉，好在 harness/安全层（沙箱、权限校验、可观测性、回滚）会成为新的硬资产。投资人视角下，这解释了为什么 agent 安全（Auto Mode 式权限校验、可审计沙箱）正在从合规成本变成产品卖点，值得盯这类基础设施公司。

How Investors Are Financing On-Site Power to Break AI Bottlenecks
The Information 报道，建设和运营数据中心的公司急于锁定推进大规模 AI 建设所需的电力，这催生了大额融资承诺和为"现场发电"（on-site power）设计的创造性交易结构，以降低数据中心对电网的依赖。投资人通过多个角度入场：一是对具体项目（如新建的现场电厂）的大额投资，二是入股提供相关电力/发电能力的公司。（正文为付费内容，以上基于公开部分。）
🦐点评：这条新闻的关键词是"on-site power"——当电力从公用事业采购变成需要自己融资、自己建厂，AI 基建的资本结构就从"租云"变成了"垂直整合能源"，性质更接近项目融资而非软件。这解释了为什么近期一批"AI+电力"标的估值抬得很快：瓶颈从 GPU 转到了并网和发电，谁手里有已获批的厂址和发电容量，谁就有定价权。对出手的印证：看数据中心公司不能只看签约的 IT 负荷（MW），要拆成"已并网容量"和"需自建发电才能兑现的容量"，后者的融资成本和时间风险此前被严重低估。同一逻辑也适用于天然气/储能/小型模块化核电板块。

深度｜Physical Coding：六角未来探索以代码驱动物理智能自进化
六角未来在技术报告里提出 "Physical Coding"：把任务相关的世界状态用代码显式写出来，让代码组织规划、行动和验证，再用物理世界的反馈回头修改工具与流程，最后把验证过的经验拿去训模型。报告先拆了现有两条路线的短板——VLA 把观测和指令直接映射成动作，但在 LIBERO 三组任务里去掉语言指令后 QwenGR00T 仍有 92.3% 成功率（保留指令才 96.2%），说明它多半是"认出场景后复现动作"而非真听懂；WAM 能预测下一帧画面，却判断不了"门外食材是否都放进了烤箱"这类物理事实。作者认为物理智能缺的不是更强动作或更漂亮的画面，而是一套可查、可改的任务状态。其系统 HexaAnything 把 Code as World（描述对象、状态、约束、进度）和 Code as Policy（组织规划、工具调用、验证与失败恢复）耦合起来，模型生成与调整这两类代码，Harness 负责运行、观测、记忆与恢复，VLA/WAM 作为工具接入，形成"执行—反馈—更新—再执行"的闭环，并把 Harness、数据与环境、模型与算法作为可进化的对象。
🦐点评：这篇的投资含义是把具身智能的竞争维度从"模型分数"拉回到"可观测、可纠错的任务状态表示"，而这恰好是仿真数据的价值所在——谁能让失败变得可定位、可复现、可转化为训练样本，谁就掌握了数据飞轮的入口，这也能解释 AMD 收购 World Labs 里 SceniX（机器人仿真）那一块。报告里那个 3.9 个百分点的差距是全文最硬的一击：VLA 在标准 benchmark 上的高分可能掺了"场景≈任务"的水分，换视角、改初始状态就掉分。对出手的启示：评估具身团队时，别只看 LIBERO 之类的成功率，要问它在未见视角/分布外场景下的退化幅度，以及失败样本能否自动回流成训练数据。

Opus 5.5：从大语言模型，到世界模型？
AGENT橘 与歸藏、杨攀、向阳乔木的聊天实录。归藏等把 Opus 5.5 的刷屏内容归为三类：纯代码生成的品牌宣传片、像素动画（难点在角色技能与场景的物理互动，比如法师打稻草人时整个屏幕随打击震动）、以及用模型操作画图工具从零把一张人像一笔笔"画"出来并录成视频。海辛只用脚本和音乐就让模型一次过做出一条有剧情、转场干净的中秋小猫视频，归藏估计这种水平已到八九十分、接很贵的单没问题（过去这类视频报价能到十万一条）。杨攀提出"世界模型"的暴论，归藏则强调它是"一位训练了十几年的艺术家"，能基于对世界的理解组合出动态作品，而不仅是理解。归藏进一步判断：如果 Opus 5.5 这类模型在动效还原上追平甚至超过 MiniMax H3，追赶难度会很高，因为 H3 智能不足、需配合大语言模型，而 Opus 5.5 是一次成片。文章还对比了剪映的"工具路线"（功能越堆越多）与 Opus 的"智能路线"（越来越强），认为智能的加速度远大于软件功能的加速度。
🦐点评：这篇文章最值得 VC 记的是一个"斩杀线"命题：純代码生成视频第一次逼近专业剪辑交付，意味着受冲击的不只是视频生成模型公司，而是整条"视频工具 + 素材 Agent + 剪辑外包"链条——被替代的是"会用软件"这层，而非"会判断怎么编排才好看"这层。归藏说的"从底层库直接拼（FFmpeg、音效库、命令行）"是关键：Opus 绕过了 AE/PR 这类 GUI 工具栈，价值因此从"工具市场份额"转向"模型 token 消耗"，这对剪映式工具的收入模型是结构性威胁。反过来看，模型厂在这条线上的护城河是"审美"，即训练数据里隐含的专业判断，这比生成本身的壁垒更高、也更难被开源追平，值得作为评估视频生成标的时的核心指标。

实录 OpenAI 年度发布会：25 项发布，逐一详解
赛博禅心对 OpenAI DevDay 2026 的逐项实录，共 25 项发布。核心是个人 agent Dots（一直在线的个人 agent，面向 Pro、Business Premium 开放，企业可配置会计/营销/法务等岗位型 Specialist Dots，并能接入微软 Agent 365）；GPT-6.1 Sol（接近 GPT-6 Astra 的智能、价格只要五分之一）；Ultrafast 档（Astra 最快 8 倍、每秒 300 token，价格为标准档 6 倍）；ChatGPT Space（人和 Dots 一起干活的协作空间，配新文档类型 Pages，协作式幻灯片几周内上线）；Decisions API（让 Luna 在零点几秒内从预设选项里做选择）；OpenAI Private Intelligence（不存内容也能做安全审查）。其他更新包括 Codex 新增 Linux 版/单项目跨多文件夹/手机端、Codex 全面上云、Codex CLI 焕新与 Codex Harness 开源、Codex Security Cloud、Agents API 增加电脑操作并与 AWS 推出 Bedrock Managed Agents、API 提速（工具调用快 30%+、首 token 快 45%+）、"用 ChatGPT 登录"覆盖 16 个合作方、插件扩展与 OpenAI Marketplace、以及新的 500 美元套餐（Plus 的 25 倍用量，含 Ultrafast，Pro 200 重新开放）。
🦐点评：这场发布会真正改变格局的不是新模型，而是 Dots 把"个人 agent"从概念推到了分发层——12 亿 ChatGPT 用户意味着它可能像当年微信公众号一样，成为 agent 的分发入口，这对独立做个人 agent 的创业公司是降维打击（你在别人的入口上抢不到用户）。同时值得警惕的是 emollick 指出的模式：OpenAI 每年发一个第三方生态又半弃用（Plugins→GPTs→Apps→Plugins），现在又给插件配了 Marketplace 和"用 ChatGPT 登录"，这一次是否能跳出"平台反复重启"的历史，要看它是否真给开发者结算和留存，而不是把生态当成拉新的筹码。对投资判断：Dots 绑定 Astra 意味着高成本默认模型，OpenAI 用 500 美元档测试 agent 的支付意愿，这一档的留存和用量会是最好的领先指标——如果它跑不动，个人 agent 的商业模式就要重新论证。
