Top 100 Consumer AI Apps - Seventh Edition
美国消费者 AI 支出高度集中：a16z 引用的 YipitData 面板中，最上面的 1% 付费者贡献 19.5% 的支出，月均花费 903 美元，付费中位数则为 25 美元。8 月该美国电子收据面板中，4.5% 的合资格消费者拥有 ChatGPT、Gemini 或 Claude 的个人付费订阅，高于一年前的 2.1%。本期首次加入消费支出榜，支出前五十名里有二十九家公司没有进入网页或移动流量榜，桌面工具与消息平台内的 Agent 因而得到不同评价。高支出人群偏爱编程、自动化和创作产品；这组数据来自美国面板，不能等同全球采用率或公司总收入。
🦐点评：榜单把 Plaud 排到消费支出第十六名，却提醒个人 Agent 还可能靠交易收费；看消费 AI，应该先分清用户是在买生产力、硬件还是代办交易，按访问量给三种生意同一估值倍数会错得很远。

Building advertising for the way people use AI
OpenAI 将于本月晚些时候在美国测试 ChatGPT 图片生成过程中的视觉广告，广告有明确标签，并与用户生成的图片分开。公司同时接入转化数据和归因伙伴，尝试用地域实验衡量广告是否真正带来新增购买。公告援引 DV Rockerbox 的早期结果称，WeightWatchers 的归因获客成本比其综合付费搜索基准低 15.3%，但这是合作伙伴报告的个案。品牌适配评估也开始引入独立机构，在受控环境下检查广告保护措施，避免向评估方开放真实私人对话。
🦐点评：Hightouch、Tealium 和 LiveRamp 接入现有客户系统，说明预算迁移还依赖数据回传和效果证明；AI 广告创业公司若只做素材生成，很容易被平台吸收，能跨平台证明增量收入的测量能力更有机会获得长期付费。
openai.com
Apple and a Hacker’s Future
Ben Thompson 自述，常驻运行 Claude 与 Codex 的 Mac Mini 遭入侵后，Claude 在监测任务中发现异常、停止执行命令并协助定位恶意软件。事故令他重新审视 macOS 的权限机制：无显示器的 Agent 主机可能被不可见的图形授权弹窗卡住，人又必须远程进入桌面批准。他认为权限应该围绕 Agent 的授权范围设计，而不是每一个临时生成的程序，并已决定将新服务器改用 Linux。文章进一步把这种体验问题延伸到家庭设备和应用入口，主张 Agent 直接操作与用户定制软件可能削弱传统应用整合方式；这是作者的使用经验和战略判断。
🦐点评：Thompson 看中 Muse Gadgets 的原因是设备把用户带回 Muse，而非单台硬件利润；投个人 Agent 周边设备，先问谁拥有持续任务关系和权限入口，硬件销量可能只是替另一家平台培养用户。
stratechery.com
Our approach to EU text provenance rules
OpenAI 宣布全球 API 客户可为部分模型主动开启文本水印，API 默认仍关闭。未来几周，欧盟地区符合条件的 ChatGPT 与 Codex 文本输出将加入不可见水印。检测器首先接受研究人员和专业机构申请，暂未向所有公众开放。公司将其定位为有局限的文本来源识别技术，与已经公开的音频、图片验证工具区别处理。
🦐点评：全球 API 可选开启、欧盟消费产品逐步默认加入，意味着同一内容工具可能同时处理有水印和无水印文本；押注单一 AI 文本检测器要谨慎，企业更可能为完整的生成记录和审核证据付费。
openai.com

深度｜百亿美金AI法律Harvey联创：应用公司不必与大模型比拼资金和算力，但要借助开源建立研究能力
Harvey 联创 Gabe Pereyra 认为，法律 AI 的研究优势可以来自真实任务评测和专业合成数据，无须复制基础模型公司的预算。由于客户法律材料高度敏感，团队先由律师设计应发现的问题和评分标准，再生成相互关联的虚拟资料室，由专业人员校正。新模型要依次经过通用评测、人工比较、产品流程测试与上线观察，简单任务可先换用开源模型，再扩展模型路由。面对通用助手，Harvey 正把重点移向多人、长周期法律项目的协调与资源管理，而不只帮助单个律师写作；文章为演讲编译。
🦐点评：Pereyra 坦言合成数据仍与真实使用有差距；评估法律 AI 的长期优势，不能只数私有文件有多少，要看客户是否愿意授权改进、合成场景能否预测真实交付质量，以及项目管理能否带来更深的组织采购。
